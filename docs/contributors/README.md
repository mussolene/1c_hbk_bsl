# docs/contributors/

Локальные записи о дизайне и ходе реализации конкретных изменений в этом
форке — контекст и обоснование решений для тех, кто продолжит работу над
той же задачей (человек или ассистент), а не пользовательская документация
проекта.

Отличие от остальных файлов в `docs/`: те описывают сам проект
(архитектуру, публичный API, правила диагностик) и релевантны апстриму.
Файлы здесь — история конкретных задач этого форка (что обсуждалось, что
проверялось на реальном коде, какие были приняты и отклонённые варианты) и
не обязаны быть релевантны или приемлемы для апстрима — при контрибьюции
изменений обратно эту папку можно свободно не включать в PR.

В отличие от `tmp/` (в `.gitignore`, чисто локальный черновик), файлы здесь
осознанно версионируются — переживают переклонирование форка.
