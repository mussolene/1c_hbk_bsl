## Настройка и подавление

Код `BSL###` — основной стабильный идентификатор. Совместимый псевдоним
принимается в `select`, `ignore` и совместимых блоковых комментариях.

```toml
[tool.onec-hbk-bsl]
select = ["BSL258"]
ignore = ["UnionAll"]
```

Все три семейства подавлений работают для текущей строки и диапазона.
Если открывающий комментарий стоит после кода, он действует только на
эту строку. Используйте любой один вариант:

- `noqa`:

```bsl
Значение = "пример";  // noqa: BSL258
```

- `bsl-disable` (совместимый вариант):

```bsl
Значение = "пример";  // bsl-disable: BSL258
```

- совместимый `BSLLS`-вариант:

```bsl
Значение = "пример";  // BSLLS:UnionAll-off
```

Если тот же открывающий комментарий стоит на отдельной строке, он
начинает диапазон. Закройте его парным маркером того же семейства:

```bsl
// noqa: BSL258
// код без этой диагностики
// noqa-enable: BSL258

// bsl-disable: BSL258
// код без этой диагностики
// bsl-enable: BSL258

// BSLLS:UnionAll-off
// код без этой диагностики
// BSLLS:UnionAll-on
```

Чтобы отключить правило до конца файла, не добавляйте закрывающий
`noqa-enable`, `bsl-enable` или `BSLLS:…-on`.

Открывающий и закрывающий маркеры должны принадлежать одному семейству.

## Configuration and suppression

`BSL###` is the primary stable identifier. The compatible alias is accepted
in `select`, `ignore`, and compatible block suppression comments.

```toml
[tool.onec-hbk-bsl]
select = ["BSL258"]
ignore = ["UnionAll"]
```

All three suppression families support both a current line and a range.
When an opening comment follows code, it affects only that line. Use any
one form:

- `noqa`:

```bsl
Value = "example";  // noqa: BSL258
```

- `bsl-disable`:

```bsl
Value = "example";  // bsl-disable: BSL258
```

- compatible `BSLLS` form:

```bsl
Value = "example";  // BSLLS:UnionAll-off
```

When the same opening comment is on a line by itself, it starts a range.
Close it with the matching marker from the same family:

```bsl
// noqa: BSL258
// code without this diagnostic
// noqa-enable: BSL258

// bsl-disable: BSL258
// code without this diagnostic
// bsl-enable: BSL258

// BSLLS:UnionAll-off
// code without this diagnostic
// BSLLS:UnionAll-on
```

To disable the rule until the end of the file, omit the closing
`noqa-enable`, `bsl-enable`, or `BSLLS:…-on` marker.

Opening and closing markers must belong to the same family.

## Описание диагностики
В общем случае, при объединении в запросе результатов нескольких запросов следует использовать конструкцию ОБЪЕДИНИТЬ ВСЕ,
а не ОБЪЕДИНИТЬ. Поскольку во втором варианте, при объединении запросов полностью одинаковые строки заменяются одной,
на что затрачивается дополнительное время, даже в случаях, когда одинаковых строк в запросах заведомо быть не может.

Исключением являются ситуации, когда выполнение замены нескольких одинаковых строк одной является необходимым условием
выполнения запроса.

## Примеры

Неправильно:
```bsl
ВЫБРАТЬ
ПоступлениеТоваровУслуг.Ссылка
ИЗ
Документ.ПоступлениеТоваровУслуг КАК ПоступлениеТоваровУслуг

ОБЪЕДИНИТЬ

ВЫБРАТЬ
РеализацияТоваровУслуг.Ссылка
ИЗ
Документ.РеализацияТоваровУслуг КАК РеализацияТоваровУслуг
```

Правильно:

```bsl
ВЫБРАТЬ
ПоступлениеТоваровУслуг.Ссылка
ИЗ
Документ.ПоступлениеТоваровУслуг КАК ПоступлениеТоваровУслуг

ОБЪЕДИНИТЬ ВСЕ

ВЫБРАТЬ
РеализацияТоваровУслуг.Ссылка
ИЗ
Документ.РеализацияТоваровУслуг КАК РеализацияТоваровУслуг
```

## Description
In most cases, when you need to combine the results of two or more queries into a single result set, employ UNION ALL clause instead of UNION. The recommendation is based on the algorithm of the UNION clause, which searches for and removes duplicates from the united result even when duplicates are impossible by the query design.

Employ UNION only when removing duplicates from the result is required.

## Examples

Incorrect:
```bsl
SELECT
GoodsReceipt.Ref
FROM
Document.GoodsReceipt AS GoodsReceipt

UNION

SELECT
GoodsSale.Ref
FROM
Document.GoodsSale AS GoodsSale
```

Correct:

```bsl
SELECT
GoodsReceipt.Ref
FROM
Document.GoodsReceipt AS GoodsReceipt

UNION ALL

SELECT
GoodsSale.Ref
FROM
Document.GoodsSale AS GoodsSale
```
