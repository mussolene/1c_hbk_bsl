## Описание диагностики

Не следует непосредственно удалять элементы коллекции при ее обходе через синтаксическую конструкцию
**Для каждого ... Из ... Цикл**. Т.к. при удалении элемента сдвигается индекс следующего элемента.

Например:

```bsl
Для Каждого Элемент Из Коллекция Цикл
   Коллекция.Удалить(Элемент)
КонецЦикла;
```

Как вариант удаляйте элементы с конца:

```bsl
ТекущийИндекс = Числа.ВГраница();
Пока ТекущийИндекс >= 0 Цикл
    Если Числа[ТекущийИндекс] < 10 Тогда
        Числа.Удалить(ТекущийИндекс);
    КонецЕсли;
    ТекущийИндекс = ТекущийИндекс – 1;
КонецЦикла;
```

## Description

Don't delete elements of collection when iterating through collection using the operator **For each ... In ... Do**. Because it change index of next element.

Example:

```bsl
For each Element In Collection Do
   Collection.Delete(Element)
EndDo;
```

Alternatively, remove elements from the end:

```bsl
IndexOf = Numbers.UBound();
While IndexOf >= 0 Do
    If Numbers[IndexOf] < 10 Then
        Numbers.Delete(IndexOf);
    EndIf;
    IndexOf = IndexOf – 1;
EndDo;
```

## Standard And Product Decision

- Standard or product policy: code must not delete from a collection while iterating that same collection with `Для каждого ... Из ... Цикл`.
- Why this diagnostic exists: mutating a collection during foreach traversal can skip elements, corrupt traversal semantics, or raise runtime errors.
- Non-goals: deleting from a different collection, deleting outside the foreach body, unsupported indirect aliases, and syntax-error ownership.
- Keep/drop decision: keep as a BSLLS-compatible collection mutation diagnostic.

## Semantic Oracle

- Checked language fact: a foreach loop iterates a collection and the loop body calls `Удалить`/`Delete` on that same collection.
- Must diagnose when: a `for_each_statement` iterates collection `X` and a direct call `X.Удалить(...)` or `X.Delete(...)` appears in the loop body before the matching loop end.
- Must not diagnose when: the delete call targets a different collection, appears outside the loop body, or the loop is malformed.
- Diagnostic anchor token/range: the delete call statement range.
- Quick-fix target, if any: collect items to delete and remove them after iteration, or iterate by index when safe.

## Examples

### Invalid Examples

1. `Для Каждого Элемент Из Коллекция Цикл` with `Коллекция.Удалить(Элемент);` inside.
2. English `For Each Item In Items Do` with `Items.Delete(Item);` inside.
3. Delete call nested inside a direct child block of the same foreach body.

### Valid Negative Twins

1. Foreach over `Коллекция` with `ДругаяКоллекция.Удалить(Элемент);`.
2. Foreach over `Коллекция` and delete from `Коллекция` after `КонецЦикла`.
3. Foreach over `Коллекция` without any delete call.

### Edge Examples

- Comments: commented delete calls do not create CST call statements.
- Strings: string literals do not create delete call statements.
- Preprocessor: not a separate semantic target for this rule.
