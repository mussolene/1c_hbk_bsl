## Описание диагностики

Необязательные параметры (параметры со значениями по умолчанию) должны располагаться после обязательных параметров (без значений по умолчанию).

## Примеры

```bsl
Функция КурсВалютыНаДату(Валюта, Дата = Неопределено) Экспорт
```

## Description

Optional parameters (parameters with default values) should follow mandatory parameters (the ones without default values).

## Examples

```bsl
Function CurrencyRateOnDate(Currency, Date = Notdefined) Export
```
