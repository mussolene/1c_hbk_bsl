# BSL217 MissingTempStorageDeletion Contract

## Rule Identity

- Code: BSL217
- BSLLS compatible name: MissingTempStorageDeletion
- Rule status: implemented

## Standard And Product Decision

- Standard or product policy: Values read from temporary storage should be deleted after use when the storage address is no longer needed.
- Non-goals: Do not report `ПоместитьВоВременноеХранилище` calls; this rule tracks reads without later deletes.

## Semantic Oracle

- Checked language fact: A global `ПолучитьИзВременногоХранилища`/`GetFromTempStorage` call has no later matching `УдалитьИзВременногоХранилища`/`DeleteFromTempStorage` call in the same method or file code block.
- Must diagnose when: the same address expression is not deleted later in the same scope.
- Must diagnose when: a delete exists only for a different address expression.
- Must not diagnose when: a later delete call has a structurally equal argument expression.
- Must not diagnose when: the method name appears in comments or strings.
- Diagnostic anchor token/range: The get-from-temp-storage call expression.

## CST Or Domain Fact Model

- CST/domain object types: global method call nodes, enclosing method/file-code-block scope.
- Extracted attributes: method name, first argument structural key, call order, scope key, call range.
- Parse-error behavior: Do not report if the call/argument CST shape cannot be proved.
- Shared semantic object: Temporary-storage read call.

## Examples

### Invalid Examples

1. `Данные = ПолучитьИзВременногоХранилища(Адрес);`.
2. `Данные = GetFromTempStorage(Address);`.
3. `ПолучитьИзВременногоХранилища(Адрес); УдалитьИзВременногоХранилища(ДругойАдрес);`.

### Valid Negative Twins

1. `Данные = ПолучитьИзВременногоХранилища(Адрес); УдалитьИзВременногоХранилища(Адрес);`.
2. `Адрес = ПоместитьВоВременноеХранилище(Данные);`.
3. `"ПолучитьИзВременногоХранилища(Адрес)"` inside a string literal.
