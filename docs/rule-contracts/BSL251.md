## Standard And Product Decision

- Standard or product policy: ternary expressions reduce readability and should be replaced by explicit `Если`/`Иначе` logic when the style policy enables the rule.
- Why this diagnostic exists: `?()` compresses branching into an expression and can hide complex data decisions.
- Non-goals: proving whether the ternary is useful, measuring nested complexity, or diagnosing ternary-looking text inside strings/comments.
- Keep/drop decision: keep as a BSLLS-compatible optional readability diagnostic.

## Semantic Oracle

- Checked language fact: executable BSL source contains a ternary expression `?(condition, then, else)`.
- Must diagnose when: a complete ternary expression span is found outside strings and comments.
- Must not diagnose when: `?(` appears only inside strings/comments, or the syntax is malformed enough that no complete span can be found.
- Diagnostic anchor token/range: full ternary expression span from `?` through the matching closing parenthesis.
- Quick-fix target, if any: rewrite the expression as explicit `Если`/`Иначе` assignments or returns.

## CST Or Domain Fact Model

- Parser/tree source: shared ternary span extractor used by ternary-family diagnostics.

## Examples

### Invalid Examples

1. `Результат = ?(Условие, 1, 0);`
2. `Возврат ?(Текст = "", "", Текст + Разделитель);`
3. `Шапка.Вставить("Функция", ?(Тип = "A", "Invoice", "Basic"));`

### Valid Negative Twins

1. `Текст = "?(Условие, 1, 0)";`
2. `// Результат = ?(Условие, 1, 0);`
3. `Если Условие Тогда Результат = 1; Иначе Результат = 0; КонецЕсли;`

### Edge Examples

- Comments: ignored by the shared ternary scanner.
- Strings: ignored by the shared ternary scanner; BSL251 is allowed through the later string-overlap guard because its own fact source already excludes string contents.
- Preprocessor: ordinary source scanning applies.
- Multiline: multiline ternary ranges span from `?` to the matching closing parenthesis.
- Nested constructs: each complete ternary expression is reported.
- BSL/SDBL variants, if relevant: query text is outside this rule.
