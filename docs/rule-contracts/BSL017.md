# BSL017 Contract

## Rule Identity

- Code: BSL017
- BSLLS compatible name: CommandModuleExportMethods
- Public name/i18n key: BSL017 / CommandModuleExportMethods
- Default message/i18n key: get_rule("BSL017").message
- Description/i18n key: RULE_METADATA["BSL017"].description
- Severity: WARNING
- Parameters/defaults: path-derived command/form module classification
- Rule status: contracted

## Standard And Product Decision

- Standard or product policy: Command and form modules should not expose exported methods as a public API surface.
- Why this diagnostic exists: It prevents accidental public entry points in UI/command modules.
- Non-goals: Non-exported methods and exported methods in module kinds where export is allowed.
- Keep/drop decision: keep

## Semantic Oracle

- Checked language fact: An exported procedure/function declaration appears in a command or form module.
- Must diagnose when: `ProcInfo.is_export` is true and the file path is classified as a command/form module.
- Must not diagnose when: The method is not exported or the module kind is not command/form.
- Diagnostic anchor token/range: the method declaration line from `ProcInfo.header_col` to line end.
- Quick-fix target, if any: remove `Экспорт` / `Export` or move the API.

## CST Or Domain Fact Model

- Parser/tree source: `DocumentSnapshot.procedures` and `command_or_form_export_facts`.
- CST/domain object types: `ProcInfo`, exported method header, path-derived module kind.
- Extracted attributes: method name, kind, start line, header column, export flag, file stem/path.
- Parse-error behavior: skip missing procedure model facts; `BSL001` owns broken-document reporting.
- Textual/regex behavior, only if genuinely textual: path/module-kind classification uses filename conventions.

## Examples

### Invalid Examples

1. A command module contains an exported procedure.
2. A form module contains an exported procedure.
3. A form module contains an exported function.

### Valid Negative Twins

1. A command module contains a non-exported procedure.
2. A common module contains an exported procedure.
3. A non-form object module contains an exported method allowed by module policy.

### Edge Examples

- Comments: commented method headers are not procedure facts.
- Strings: strings are not procedure declarations.
- Preprocessor: not a separate target.
- Multiline: method header range starts at the declaration line.
- Nested constructs: methods are top-level module declarations.
- BSL/SDBL variants, if relevant: SDBL is not relevant.
