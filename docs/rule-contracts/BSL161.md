## Описание диагностики

Модули, предназначенные для реализации на сервере или на клиенте функций с повторным использованием возвращаемых
значений (на время вызова или на время сеанса), именуются с постфиксом "ПовтИсп" (англ. "Cached")
и "КлиентПовтИсп" (англ. "ClientCached") соответственно.

## Примеры

РаботаСФайламиКлиентПовтИсп, UsersInternalCached

## Источники

[Стандарт: Правила создания общих модулей](https://its.1c.ru/db/v8std#content:469:hdoc:3.2.3)

</div>

## Description

Use the "Cached" (rus. ПовтИсп) and "ClientCached" (rus. КлиентПовтИсп) postfixes for the modules that implement functions with repeated use of return values (upon the call or session time) on the server and on the client respectively.

## Examples

FilesClientCached, UsersInternalCached

## Sources

[Standard: Rules for creating common modules (RU)](https://its.1c.ru/db/v8std#content:469:hdoc:3.2.3)

## Standard And Product Decision

- Standard or product policy: cached common modules should be named so their reuse/caching behavior is visible from the module name.
- Why this diagnostic exists: `ReturnValuesReuse` changes runtime semantics; names without a cached/reuse marker make common-module behavior harder to understand.
- Non-goals: non-common modules, common modules without cached `ReturnValuesReuse`, missing/unreadable XML, and other common-module naming rules.
- Keep/drop decision: keep as a BSLLS-compatible common-module naming diagnostic.

## Semantic Oracle

- Checked language fact: a common module has cached return-value reuse and its metadata name does not contain a cached/reuse marker.
- Must diagnose when: sibling common-module XML exists, `ReturnValuesReuse` is a cached mode such as `DuringRequest` or `DuringSession`, and the module name does not match the cached-name token set.
- Must not diagnose when: XML is missing/unreadable, the metadata is not a common module, return-value reuse is not cached, or the module name already contains `ПовтИсп`, `ПовторноеИспользование`, or `Cached`.
- Diagnostic anchor token/range: the first non-empty/non-BOM line of the module file.
- Quick-fix target, if any: rename the common module to include an accepted cached/reuse marker.
