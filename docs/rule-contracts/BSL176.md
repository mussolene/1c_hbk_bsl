# BSL176 DeprecatedMethodCall Contract

## Rule Identity

- Code: BSL176
- BSLLS compatible name: DeprecatedMethodCall
- Rule status: implemented

## Standard And Product Decision

- Standard or product policy: Report use of deprecated user-defined methods and deprecated platform/configuration members that are visible through structured facts.
- Non-goals: Do not emulate BSLLS type service guesses when the project metadata or CST surface cannot prove the referenced member.

## Semantic Oracle

- Checked language fact: A call or member access targets an API element marked as deprecated.
- Must diagnose when: A non-deprecated procedure calls a same-file procedure/function whose leading documentation says `Deprecated.` or `Устарела.`.
- Must diagnose when: A call graph edge targets a known deprecated platform global/member method.
- Must diagnose when: A CST `property_access` targets a metadata member whose technical name starts with `Удалить` or `Delete` and whose object/member is present in `SymbolIndex` metadata.
- Must diagnose when: Future platform API metadata marks another resolved member as deprecated for the active compatibility mode.
- Must not diagnose when: The deprecated local method is called from another deprecated local method.
- Must not diagnose when: The text is inside comments or string literals.
- Must not diagnose when: The CST node is a method call rather than property access.
- Diagnostic anchor token/range: The deprecated method/property identifier only.

## CST Or Domain Fact Model

- CST/domain object types: `method_call`, call graph edge, local symbol doc comment, `property_access`, metadata object/member rows.
- Extracted attributes: callee name, caller name, doc comment, receiver chain, property token, metadata object name, metadata member kind.
- Parse-error behavior: Keep local call-graph behavior; metadata property access requires a valid CST property access node.
- Shared semantic object: Deprecated API use site.

## Examples

### Invalid Examples

1. `СтарыйМетод();` where `СтарыйМетод` has a leading `// Deprecated.` documentation block.
2. `ПодробноеПредставлениеОшибки(ИнформацияОбОшибке());`.
3. `Метаданные.Справочники.Контрагенты.УдалитьСтарыйРеквизит;` when that metadata member exists.

### Valid Negative Twins

1. `СтарыйМетод();` from inside another deprecated method.
2. `"Метаданные.Справочники.Контрагенты.УдалитьСтарыйРеквизит"` inside a string literal.
3. `Метаданные.Справочники.Контрагенты.УдалитьСтарыйМетод();` because deleted-prefix matching is property-only.
