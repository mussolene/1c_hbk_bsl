# BSL040 Contract

- Severity: INFORMATION
- Parameters/defaults: none
- Rule status: contracted

## Standard And Product Decision

- Standard or product policy: Managed UI code should not depend on the deprecated form-context property `ЭтаФорма` / `ThisForm`; pass the form explicitly when a helper method needs it.
- Why this diagnostic exists: It prevents hidden coupling to the current form object in form modules.
- Non-goals: Strings, comments, non-form modules, and local parameters named `ЭтаФорма` / `ThisForm` are not deprecated property access facts.
- Keep/drop decision: keep

## Semantic Oracle

- Checked language fact: A real identifier token `ЭтаФорма` or `ThisForm` used in a full EDT form module when it is not a method parameter shadowing that name.
- Must diagnose when: A full form module body references `ЭтаФорма` or `ThisForm` as code.
- Must not diagnose when: The same text appears in comments, string literals, non-form modules, split module fragments, non-canonical side `.bsl` files below a form `Ext` directory, or a method that declares a parameter with the same name.
- Diagnostic anchor token/range: the identifier token `ЭтаФорма` / `ThisForm`.
- Quick-fix target, if any: none

## CST Or Domain Fact Model

- Parser/tree source: BSL document snapshot with tree-sitter procedure metadata plus path-derived module-kind context.
- CST/domain object types: identifier occurrence, `ProcInfo` for containing procedure, and canonical full form module path context.
- Extracted attributes: line index, LSP character range, containing procedure parameters, and canonical full-form-module/split-fragment classification.
- Parse-error behavior: skip malformed structural interpretation except for textual occurrences that remain in a tree-built snapshot; `BSL001` owns broken-document diagnostics.
- Textual/regex behavior, only if genuinely textual: token search is textual after strings and comments are masked because the rule detects a deprecated identifier spelling.

## Examples

### Invalid Examples

1. Full form module procedure calls `ЭтаФорма.Закрыть();`.
2. Full form module procedure passes `ThisForm` into a helper call.
3. Full form module function reads a property through `ЭтаФорма`.

### Valid Negative Twins

1. Common module code contains `ЭтаФорма.Закрыть();`.
2. Full form module has `Процедура Команда(ЭтаФорма)` and uses that parameter.
3. Full form module contains `"ЭтаФорма"` in a string literal or `// ЭтаФорма` in a comment.

### Edge Examples

- Comments: masked before fact creation.
- Strings: masked before fact creation.
- Preprocessor: not a special target; normal code lines are inspected after masking.
- Multiline: each identifier occurrence is anchored on its own line.
- Nested constructs: containing procedure parameter shadowing suppresses occurrences inside that procedure.
- BSL/SDBL variants, if relevant: not relevant.

- Delta category fixed by this change: product-decision classification for legacy ordinary-form module layout; previous BSLLS-zero result was a temp-copy harness defect.
