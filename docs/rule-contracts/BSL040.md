## Описание диагностики

В версии платформы 1С Предприятие 8.3.3 свойство формы ```ЭтаФорма``` было признано устаревшим. Вместо него следует использовать свойство ```ЭтотОбъект```

## Description

In the version of the platform 1C Enterprise 8.3.3, the property of the form ```ThisForm``` was deprecated. Instead, use the property ```ThisObject```
