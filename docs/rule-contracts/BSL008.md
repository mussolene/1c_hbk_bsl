## Описание диагностики

Большое количество возвратов в методе (процедуре или функции) увеличивает его сложность и снижает производительность и восприятие.

## Примеры

Пример плохого метода

```bsl
Функция Пример(Условие)
    Если Условие = 1 Тогда
        Возврат "Проверка пройдена";
    ИначеЕсли Условие = 2 Тогда
        ВыполнитьДействие();
        Возврат "Проверка не пройдена";
    ИначеЕсли Условие > 7 Тогда
        Если ВыполнитьПроверку(Условие) Тогда
            Возврат "Проверка пройдена";
        Иначе
            Возврат "Проверка не пройдена";
        КонецЕсли;
    КонецЕсли;
    Возврат "";
КонецФункции
```

## Description

A large number of returns in a method (procedure or function) increases its complexity and reduces performance and perception.

## Examples

Bad method example

```bsl
Function Example(Condition)
     If Condition = 1 Then
         Return "Check passed";
     ElsIf Condition = 2 Then
         ExecuteSomething();
         Return "Check not passed";
     ElsIf Condition > 7 Then
         Если Validate(Contidtion) Then
             Return "Check passed";
         Else
             Return "Check not passed";
         EndIf;
     EndIf;
     Return "";
EndFunction
```

## Standard And Product Decision

- Standard or product policy: methods should keep exit points limited enough that control flow remains easy to audit.
- Why this diagnostic exists: too many `Возврат` / `Return` statements make method behavior harder to reason about and usually indicate a method that should be simplified or split.
- Non-goals: do not diagnose methods at or below the configured threshold; do not diagnose return-like words in comments or strings; do not check query text.
- Keep/drop decision: keep as a BSLLS-compatible method contract diagnostic.

## Semantic Oracle

- Checked language fact: a procedure or function contains more return statements than the configured `max_returns` threshold.
- Must diagnose when: the count of executable `Возврат` / `Return` statements inside one method body is greater than `max_returns`.
- Must not diagnose when: the return count is less than or equal to `max_returns`, or apparent return tokens appear only in comments, strings, or outside the method body.
- Diagnostic anchor token/range: method name range resolved through the shared `proc_name_span` helper.
- Quick-fix target, if any: none.

## CST Or Domain Fact Model

- Parser/tree source: `DocumentSnapshot.procedures` / `ProcInfo` method ranges and masked method body lines.
- CST/domain object types: `ProcInfo` procedure/function body plus return-statement lexical facts.
- Extracted attributes: method start/end line, method header column, configured max return threshold, return token count.
- Parse-error behavior: skip uncertain procedure containment when the procedure model is unavailable; BSL001 owns syntax errors.
- Textual/regex behavior, only if genuinely textual: current implementation uses `_RE_RETURN` over a method-body slice; it must operate on code facts that exclude comments and strings.

## Examples

### Invalid Examples

1. A function with four `Возврат` statements when `max_returns=3`.
2. A procedure with four early `Возврат;` guard exits when `max_returns=3`.
3. A method with nested branches whose total executable return statements exceeds the threshold.

### Valid Negative Twins

1. A function with exactly three `Возврат` statements when `max_returns=3`.
2. A method with return-like words only in comments.
3. A method with return-like words only in string literals.

### Edge Examples

- Comments: return-like tokens in comments do not count.
- Strings: return-like tokens in strings do not count.
- Preprocessor: visible return statements inside a parsed method count normally; inactive preprocessor branch handling is not owned by this rule.
- Multiline: a multiline method header still anchors the method diagnostic on the method header fact.
- Nested constructs: nested branches do not create separate scopes; all executable returns in the method count together.
- BSL/SDBL variants, if relevant: SDBL query text is not a target.
