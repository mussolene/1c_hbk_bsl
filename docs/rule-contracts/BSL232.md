- Правило сообщает о случаях, описанных на этой странице.

## Настройка и подавление

Код `BSL###` — основной стабильный идентификатор. Совместимый псевдоним
принимается в `select`, `ignore` и совместимых блоковых комментариях.

```toml
[tool.onec-hbk-bsl]
select = ["BSL232"]
ignore = ["ProtectedModule"]
```

Подавить диагностику только на текущей строке:

```bsl
Значение = "пример";  // noqa: BSL232
Значение = "пример";  // bsl-disable: BSL232
```

Отключить правило для блока или всего файла:

```bsl
// BSLLS:ProtectedModule-off
// код без этой диагностики
// BSLLS:ProtectedModule-on
```

## Configuration and suppression

`BSL###` is the primary stable identifier. The compatible alias is accepted
in `select`, `ignore`, and compatible block suppression comments.

```toml
[tool.onec-hbk-bsl]
select = ["BSL232"]
ignore = ["ProtectedModule"]
```

Suppress the diagnostic on the current line:

```bsl
Value = "example";  // noqa: BSL232
Value = "example";  // bsl-disable: BSL232
```

Disable the rule for a block or the whole file:

```bsl
// BSLLS:ProtectedModule-off
// code without this diagnostic
// BSLLS:ProtectedModule-on
```

## Описание диагностики

Отсутствие исходников модуля в конфигурации не рекомендуется.
В случае закрытого, запароленного модуля понижается качество кода, нельзя сделать ревью кода, версионирование изменений не ведется.

## Description

The absence of module sources in the configuration is not recommended.
