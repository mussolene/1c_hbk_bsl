# BSL185 ExternalAppStarting Contract

## Rule Identity

- Code: BSL185
- BSLLS compatible name: ExternalAppStarting
- Public name/i18n key: BSL185 / ExternalAppStarting
- Default message/i18n key: RULE_MESSAGES_RU["BSL185"]
- Description/i18n key: RULE_METADATA["BSL185"].description
- Severity: ERROR
- Parameters/defaults: `checkGotoUrl=false`; default `userPatternString` method set is supported.
- Rule status: verified

## Standard And Product Decision

- Standard or product policy: launching external applications from BSL is a potential vulnerability and must be reviewed.
- Why this diagnostic exists: external process launch can execute untrusted commands or open unsafe local resources.
- Non-goals: declarations of wrapper methods with the same name, comments, strings, member-call semantics beyond the default BSLLS pattern, and optional navigation-link checks disabled by default.
- Keep/drop decision: keep as a BSLLS-compatible security diagnostic.

## Semantic Oracle

- Checked language fact: executable BSL code calls a default external-application starting method.
- Must diagnose when: a source line calls one of the default configured method names such as `КомандаСистемы`, `ЗапуститьПриложение`, `НачатьЗапускПриложения`, `ЗапуститьПрограмму`, `ОткрытьПроводник`, or `ОткрытьФайл`.
- Must not diagnose when: the name appears in a procedure/function declaration, comment, or string.
- Diagnostic anchor token/range: external-start method name.
- Quick-fix target, if any: replace with a safe reviewed wrapper or remove external process launch.

- Parser/tree source: masked source lines.
