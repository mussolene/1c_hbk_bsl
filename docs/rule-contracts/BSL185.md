## Описание диагностики

Для повышения качества и безопасности решения на 1С необходимо контролировать запуск внешних приложений из кода 1С.

Данное правило распространяется на все способы запуска внешних программ, в том числе:
- КомандаСистемы
- ЗапуститьСистему
- ЗапуститьПриложение
- НачатьЗапускПриложения
- ЗапуститьПриложениеАсинх
- ПерейтиПоНавигационнойСсылке или ФайловаяСистемаКлиент.ОткрытьНавигационнуюСсылку
- ФайловаяСистемаКлиент.ЗапуститьПрограмму (в клиентском коде) и ФайловаяСистема.ЗапуститьПрограмму (в серверном коде)
- ФайловаяСистемаКлиент.ОткрытьПроводник
- ФайловаяСистемаКлиент.ОткрытьФайл

## Description

To improve the quality and security of 1C solutions, it is necessary to control the launch of external applications from 1C code.

This rule applies to all methods of launching external programs, including:
- System
- RunSystem
- RunApp
- BeginRunningApplication
- RunAppAsync
- GotoURL or FileSystems.OpenURL
- FileSystemsClient.RunApp (for client side) and FileSystems.RunApp (for server side)
- FileSystemClient.OpenExplorer
- FileSystemClient.OpenFile

## Standard And Product Decision

- Standard or product policy: launching external applications from BSL is a potential vulnerability and must be reviewed.
- Why this diagnostic exists: external process launch can execute untrusted commands or open unsafe local resources.
- Non-goals: declarations of wrapper methods with the same name, comments, strings, member-call semantics beyond the default BSLLS pattern, and optional navigation-link checks disabled by default.
- Keep/drop decision: keep as a BSLLS-compatible security diagnostic.

## Semantic Oracle

- Checked language fact: executable BSL code calls a default external-application starting method.
- Must diagnose when: a source line calls one of the default configured method names such as `КомандаСистемы`, `ЗапуститьПриложение`, `НачатьЗапускПриложения`, `ЗапуститьПрограмму`, `ОткрытьПроводник`, or `ОткрытьФайл`.
- Must not diagnose when: the name appears in a procedure/function declaration, comment, or string.
- Diagnostic anchor token/range: external-start method name.
- Quick-fix target, if any: replace with a safe reviewed wrapper or remove external process launch.

## CST Or Domain Fact Model

- Parser/tree source: masked source lines.
- CST/domain object types: textual call-name facts from the default BSLLS user pattern.
- Extracted attributes: method name and method-name range.
