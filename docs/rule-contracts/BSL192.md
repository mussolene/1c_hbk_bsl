## Описание диагностики

В имени функции слово получить лишнее т.к. функция по определению возвращает значение.

## Примеры
```bsl
// Не правильно:
Функция ПолучитьИмяПоКоду()

// Правильно:
Функция ИмяПоКоду()
```

## Источники
* Источник: [Стандарт: Имена процедур и функций п 6.1](https://its.1c.ru/db/v8std#content:647:hdoc)

## Description

In the name of the function, the word get superfluous since function by definition returns a value.

## Examples
```bsl
// Incorrect:
Function GetNameByCode()

// Correct:
Function NameByCode()
```

## Sources
* Source: [Standard: Names of procedures and functions c 6.1 (RU)](https://its.1c.ru/db/v8std#content:647:hdoc)
