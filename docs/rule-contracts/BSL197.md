## Standard And Product Decision

- Standard or product policy: branches of one `Если...Тогда...ИначеЕсли...Иначе` chain should not contain identical code blocks.
- Why this diagnostic exists: duplicated branch bodies usually mean a copy-paste mistake or a condition chain that can be simplified.
- Non-goals: detecting semantically equivalent but textually/structurally different code, cross-method duplication, or ordinary repeated statements outside one conditional chain.
- Keep/drop decision: keep as a BSLLS-compatible suspicious-code diagnostic.

## Semantic Oracle

- Checked language fact: two or more executable branch bodies inside one conditional chain have the same CST structure and leaf text after case normalization for identifiers and keywords.
- Must diagnose when: an earlier branch body is structurally identical to any later branch body in the same `if_statement`.
- Must not diagnose when: branch bodies differ by identifier, literal, statement order, statement count, or nested structure.
- Diagnostic anchor token/range: the first duplicated branch body range, from the first code node through the last code node in that branch.
- Quick-fix target, if any: manually remove duplication, merge conditions, or adjust the branch body.

## CST Or Domain Fact Model

- Parser/tree source: BSL CST `if_statement` nodes.
- CST/domain object types: `if_statement`, `elseif_clause`, `else_clause`, and branch body child nodes.
- Extracted attributes: ordered branch body nodes and `_structural_node_key` for each body node.
- Parse-error behavior: malformed conditional syntax is owned by BSL001; this rule only compares branch bodies present in CST.
- Textual/regex behavior, only if genuinely textual: none.

## Examples

### Invalid Examples

1. `Если А Тогда\n    Результат = 1;\nИначеЕсли Б Тогда\n    Результат = 1;\nКонецЕсли;`
2. `Если А Тогда\n    ВыполнитьДействие();\nИначе\n    ВыполнитьДействие();\nКонецЕсли;`
3. `Если А Тогда\n    Если Б Тогда\n        Возврат;\n    КонецЕсли;\nИначеЕсли В Тогда\n    Если Б Тогда\n        Возврат;\n    КонецЕсли;\nКонецЕсли;`

### Valid Negative Twins

1. `Если А Тогда\n    Результат = 1;\nИначеЕсли Б Тогда\n    Результат = 2;\nКонецЕсли;`
2. `Если А Тогда\n    Первый();\n    Второй();\nИначе\n    Второй();\n    Первый();\nКонецЕсли;`
3. `Если А Тогда\n    Результат = ЗначениеА;\nИначе\n    Результат = ЗначениеБ;\nКонецЕсли;`

### Edge Examples

- Comments: comment-only differences are ignored because comments are not code body nodes.
- Strings: string literal text participates in the structural key.
- Preprocessor: not a separate semantic target.
- Multiline: body range may span several statements or nested blocks.
- Nested constructs: nested CST structure participates in the structural key.
- BSL/SDBL variants, if relevant: query text is not a separate target for this rule.
