## Standard And Product Decision

- Standard or product policy: `ЗафиксироватьТранзакцию` / `CommitTransaction` must be the last statement in a `Попытка` block before `Исключение`.
- Why this diagnostic exists: code after commit inside the try block can throw and leave transaction error handling unsafe or misleading.
- Non-goals: begin/rollback placement, counterpart pairing, nested transaction counting, or full data-flow analysis.
- Keep/drop decision: keep as a BSLLS-compatible transaction-safety diagnostic.

## Semantic Oracle

- Checked language fact: a commit-transaction call is followed by another executable statement before `Исключение` or `КонецПопытки`.
- Must diagnose when: `ЗафиксироватьТранзакцию()` / `CommitTransaction()` is not the final meaningful statement before the try block transitions to exception/end.
- Must not diagnose when: commit is immediately followed by `Исключение` / `Except` after blank/comment-only lines.
- Diagnostic anchor token/range: the commit-transaction call line span.
- Quick-fix target, if any: move `ЗафиксироватьТранзакцию` to the end of the try block immediately before `Исключение`.

## Examples

### Invalid Examples

1. `Попытка ЗафиксироватьТранзакцию(); Сообщить("после"); Исключение ...`
2. `Try CommitTransaction(); Value = 1; Except ...`
3. `Попытка ЗафиксироватьТранзакцию(); КонецПопытки`

### Valid Negative Twins

1. `Попытка Действие(); ЗафиксироватьТранзакцию(); Исключение ... КонецПопытки`
2. `НачатьТранзакцию(); Попытка ЗафиксироватьТранзакцию(); Исключение ОтменитьТранзакцию(); КонецПопытки`
3. `Попытка Действие(); Исключение ОтменитьТранзакцию(); КонецПопытки`

### Edge Examples

- Comments: ignored by snapshot comment stripping.
- Strings: fixed call matching is anchored at line start and does not inspect string contents.
- Preprocessor: ordinary line order applies.
- Multiline: current rule targets line-local commit calls.
- Nested constructs: pending commit resets at try/except/end-try boundaries.
- BSL/SDBL variants, if relevant: query text is outside this rule.
