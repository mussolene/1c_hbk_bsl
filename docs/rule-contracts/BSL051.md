# BSL051 UnreachableCode Contract

## Rule Identity

- Code: BSL051
- BSLLS compatible name: UnreachableCode
- Public name/i18n key: BSL051 / UnreachableCode
- Default message/i18n key: RULE_MESSAGES_RU["BSL051"]
- Description/i18n key: RULE_METADATA["BSL051"].description
- Severity: ERROR
- Parameters/defaults: none.
- Rule status: verified

## Standard And Product Decision

- Standard or product policy: code after unconditional control-flow exit in the same execution path is dead code and should be removed or moved before the exit.
- Why this diagnostic exists: unreachable code usually indicates accidental leftovers, disabled logic, or incorrect control flow after editing.
- Non-goals: full symbolic execution, data-dependent reachability, syntax diagnostics, and dead branches that require expression evaluation.
- Keep/drop decision: keep as a BSLLS-compatible suspicious dead-code diagnostic.

## Semantic Oracle

- Checked language fact: an executable statement is placed after an unconditional exit statement in the same method/control-flow segment.
- Must diagnose when: code follows `Возврат`/`Return`, `Перейти`/`Goto`, `ВызватьИсключение`/`Raise`, `Прервать`/`Break`, or `Продолжить`/`Continue` before the enclosing block can execute further.
- Must not diagnose when: the next non-comment token is a method end, an ordinary block delimiter, or code remains reachable through another branch.
- Diagnostic anchor token/range: the first unreachable executable statement, extending to the skipped block end when the unreachable statement starts a block.
- Quick-fix target, if any: remove unreachable code, move it before the exit, or restructure the control flow.

## CST Or Domain Fact Model

- Parser/tree source: procedure facts plus CST block delimiter lines for clean trees; text delimiter fallback only when the full file CST is dirty.
- CST/domain object types: `ProcInfo`, method body lines, unconditional-exit statements, delimiter keyword lines, all-branch-exit `if` summaries, and diagnostic ranges.
- Extracted attributes: method start/end lines, statement indentation, exit keyword, block delimiter line set, preprocessor crossing state, branch-exit state, and severity.
- Parse-error behavior: BSL001 owns syntax errors; BSL051 still reports local unreachable code inside extracted methods when the full-file tree is dirty, using conservative textual delimiter lines.
- Textual/regex behavior, only if genuinely textual: exit-keyword and dirty-tree delimiter fallback matching are textual over already extracted method bodies.

## Examples

### Invalid Examples

1. `Возврат; Сообщить("никогда");`
2. `Прервать; Сообщить("после прерывания");`
3. `Если А Тогда Возврат 1; Иначе Возврат 2; КонецЕсли; Результат = 3;`

### Valid Negative Twins

1. `Сообщить("до выхода"); Возврат;`
2. `Если А Тогда Возврат; КонецЕсли; Сообщить("reachable");`
3. `Попытка А = 1; Исключение Возврат; КонецПопытки`

### Edge Examples

- Comments: skipped when searching for the first unreachable executable line.
- Strings: ignored because reachability is statement-level.
- Preprocessor: crossing preprocessor directives suppresses the simple same-segment emission.
- Multiline: the first unreachable statement line anchors the diagnostic; block starts extend to the block end.
- Nested constructs: all branches of an `if` ending in unconditional exits make following same-level code unreachable.
- BSL/SDBL variants, if relevant: query text is outside this rule.

## Implementation Decision

- Change target: `ModuleModel.validate_bsl051_unreachable_code` dirty-CST fallback, targeted regression test, and compiled regex reuse in the BSL051 hot path.
- Delta category fixed by this change: one BSLLS-only false negative caused by skipping BSL051 for the whole file when the CST had any parse error.
- Why not another layer: existing method-body control-flow scanner already matched BSLLS when enabled; the defect was the full-file CST-error gate.
- Rollback signal: dirty files lose local BSL051 diagnostics again, block delimiters report as unreachable code, or selected parity gains BSL051 deltas.
