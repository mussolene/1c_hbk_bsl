## Описание диагностики

Для разделения блоков кода между собой используется вставка пустой строки.

Вставка 2-х и более пустых строк не несет данной ценности и приводит к бессмысленному увеличению длины метода или модуля.

</div>

<div class="doc-lang doc-lang-en" markdown="1">

## Description

To separate blocks of code among themselves, insert an empty line.

Inserting 2 or more empty lines does not carry this value and leads to a meaningless increase in the length of the method or module.

</div>
