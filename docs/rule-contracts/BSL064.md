## Описание диагностики

`Процедура`, в отличие от `Функции` не может возвращать значения. Эта диагностика находит процедуры, где есть `Возврат` со значением.

</div>

<div class="doc-lang doc-lang-en" markdown="1">

## Description

`Procedure`, unlike a `Function` cannot return values. This diagnostic finds procedures where there is a `Return` statement with a value.

</div>

## Standard And Product Decision

- Standard or product policy: `Процедура` / `Procedure` must not return a value; value-returning routines must be functions.
- Why this diagnostic exists: `Возврат` with an expression inside a procedure is a language/semantic error and hides an API contract mismatch.
- Non-goals: empty `Возврат;` in procedures, return-path completeness for functions, or excessive-return style checks.
- Keep/drop decision: keep as a BSLLS-compatible correctness diagnostic.

## Semantic Oracle

- Checked language fact: a procedure body contains a `return_statement` with an expression child.
- Must diagnose when: `Возврат <expression>;` / `Return <expression>;` appears inside a procedure.
- Must not diagnose when: the return statement is empty, or the same return-with-expression appears inside a function.
- Diagnostic anchor token/range: full CST return statement span.
- Quick-fix target, if any: remove the returned expression or convert the procedure to a function when the API contract requires a value.

## CST Or Domain Fact Model

- Parser/tree source: procedure facts mapped to tree-sitter procedure definition nodes.
- CST/domain object types: `ProcInfo`, procedure definition node, `return_statement`, and expression child.
- Extracted attributes: method kind, method start line, return statement range, expression presence, and severity.
- Parse-error behavior: skip methods whose CST node cannot be mapped; BSL001 owns syntax errors.
- Textual/regex behavior, only if genuinely textual: none for the semantic decision; range coordinates are derived from CST byte positions.

## Examples

### Invalid Examples

1. `Процедура Тест() Возврат 42; КонецПроцедуры`
2. `Procedure Test() Return Result; EndProcedure`
3. `Процедура Тест() Если А Тогда Возврат А; КонецЕсли; КонецПроцедуры`

### Valid Negative Twins

1. `Процедура Тест() Возврат; КонецПроцедуры`
2. `Функция Тест() Возврат 42; КонецФункции`
3. `Процедура Тест() А = 42; КонецПроцедуры`
