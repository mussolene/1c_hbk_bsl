## Описание диагностики
В формах и модулях объектов избыточно обращаться к реквизитам через ЭтотОбъект. В общих модулях избыточно обращаться к методам через свое имя, кроме модулей с ПовтИсп.

## Примеры
В модуле объекта документа с реквизитом `Контрагент` неправильно писать
```bsl
ЭтотОбъект.Контрагент = ПолучитьКонтрагента();
```

правильно будет обратиться к реквизиту напрямую
```bsl
Контрагент = ПолучитьКонтрагента();
```

В общем модуле `ОбщегоНазначения` неправильным будет такой вызов метода
```bsl
ОбщегоНазначения.СообщитьПользователю("ru = 'Привет мир!'");
```

а правильным
```bsl
СообщитьПользователю("ru = 'Привет мир!'");
```

## Description
In the forms and modules of objects, it is wrong to refer to the attributes through the property ThisObject. In common modules, it is redundant to refer to methods through their name, except for modules with Cashed.

## Examples
In the ObjectModule of the Document with the attribute `Countractor`, it is wrong to use
```bsl
ThisObject.Contractor = GetContractor();
```

correctly use the props directly
```bsl
Contractor = GetContractor();
```

In the common module `Commons`, the following method call will be incorrect
```bsl
Commons.SendMessage("en = 'Hi!'");
```

correct
```bsl
SendMessage("en = 'Hi!'");
```

## Standard And Product Decision

- Standard or product policy: redundant self-object qualification makes object/form/common-module code noisier and can obscure the real receiver.
- Why this diagnostic exists: `ЭтотОбъект.` / `ThisObject.` and common-module self-name receivers are unnecessary in supported module contexts.
- Non-goals: do not diagnose arbitrary dotted receivers, method calls where receiver self-name is intentionally used as a returned object, or unsupported file/module contexts.
- Keep/drop decision: keep as a BSLLS-compatible readability/performance diagnostic.

## Semantic Oracle

- Checked language fact: a supported module context contains an unnecessary self-object receiver prefix before a member/property access.
- Must diagnose when: object, recordset, manager, or form module code uses `ЭтотОбъект.` / `ThisObject.` as redundant receiver, or a common module calls itself through its module name in BSLLS-supported contexts.
- Must not diagnose when: the prefix appears in comments/strings, unsupported module files, or a method-call reuse context that BSLLS skips.
- Diagnostic anchor token/range: redundant receiver prefix without the final member name.
- Quick-fix target, if any: remove the redundant receiver prefix.

## Examples

### Invalid Examples

1. `ЭтотОбъект.Реквизит = 1;` in an object module.
2. `ThisObject.Property = 1;` in an object module.
3. A form module reads `ЭтотОбъект.ЭлементФормы`.

### Valid Negative Twins

1. `ДругойОбъект.Реквизит = 1;`.
2. `"ЭтотОбъект.Реквизит"` inside a string.
3. `// ЭтотОбъект.Реквизит = 1;`.

### Edge Examples

- Comments: line comments are ignored.
- Strings: double-quoted strings are masked before matching.
- Preprocessor: no separate semantic target.
- Multiline: redundant prefix is diagnosed on the line where it appears.
- Nested constructs: nested blocks do not change the receiver-prefix rule.
