# BSL195 GetFormMethod Contract

## Rule Identity

- Code: BSL195
- BSLLS compatible name: GetFormMethod
- Rule status: implemented

## Standard And Product Decision

- Standard or product policy: Opening forms through `ОткрытьФорму`/`OpenForm` is preferred; getting a form object through `ПолучитьФорму`/`GetForm` and opening it manually is discouraged.
- Non-goals: Do not diagnose text inside comments or string literals.

## Semantic Oracle

- Checked language fact: Code calls a method named `ПолучитьФорму` or `GetForm`.
- Must diagnose when: the call is global.
- Must diagnose when: the call is receiver-qualified, such as `Док.ПолучитьФорму(...)`.
- Must not diagnose when: the name is only a prefix of a longer identifier.
- Must not diagnose when: the text is inside comments or string literals.
- Diagnostic anchor token/range: The `ПолучитьФорму`/`GetForm` method-name token.

## CST Or Domain Fact Model

- CST/domain object types: masked source line, method-call token.
- Extracted attributes: method name, line, start column, end column.
- Parse-error behavior: Line-local complete calls may still be reported in otherwise broken files.
- Shared semantic object: Deprecated form retrieval method call.

## Examples

### Invalid Examples

1. `Форма = ПолучитьФорму("Обработка.УниверсальныйРедактор.Форма");`.
2. `Форма = Док.ПолучитьФорму("ФормаДокумента");`.
3. `Form = Object.GetForm("Form");`.

### Valid Negative Twins

1. `Текст = "ПолучитьФорму()"`.
2. `// Форма = ПолучитьФорму("Форма");`.
3. `ПолучитьФормуДокумента();`.
