## Описание диагностики
В модулях управляемых форм и общих модулях не должно быть переменной с именем "ЭтотОбъект".

Часто ошибка появляется при поднятии версии режима совместимости конфигурации т.к. в версиях до 8.3.3
свойство "ЭтотОбъект" у управляемых форм и общих модулей отсутствовало. И могло быть
использовано как переменная.

## Примеры

Неправильно:
```bsl

ЭтотОбъект = РеквизитФормыВЗначение("Объект");

```

## Description
In managed form modules and common modules, there should not be a variable named "ThisObject".

Often this error appears when updating the platform version: the "ThisObject" property of managed forms and common modules appeared in version 8.3.3 which could previously be used as a variable name.

## Examples

Incorrect:
```bsl

ThisObject = FormAttributeToValue("Object");

```
