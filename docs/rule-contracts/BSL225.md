# BSL225 NumberOfValuesInStructureConstructor Contract

## Rule Identity

- Code: BSL225
- BSLLS compatible name: NumberOfValuesInStructureConstructor
- Rule status: implemented

## Standard And Product Decision

- Standard or product policy: Structure constructors should not receive more than three property values; use explicit `Вставить` calls or assignments for readability.
- Non-goals: Do not count the first constructor argument containing property names as a property value.

## Semantic Oracle

- Checked language fact: `Новый Структура`/`New Structure` or `Новый ФиксированнаяСтруктура`/`New FixedStructure` has more than `maxValuesCount` value arguments after the key-list argument.
- Must diagnose when: the constructor has four or more value arguments with default `maxValuesCount = 3`.
- Must diagnose when: the type is `ФиксированнаяСтруктура`/`FixedStructure`.
- Must not diagnose when: there are three or fewer value arguments.
- Must not diagnose when: the constructor type is not Structure/FixedStructure.
- Diagnostic anchor token/range: The whole `new_expression`.

## CST Or Domain Fact Model

- CST/domain object types: `new_expression`, type identifier, `arguments` children.
- Extracted attributes: type name, top-level argument count, expression range.
- Parse-error behavior: Do not report if the constructor or argument CST shape is unavailable.
- Shared semantic object: Structure constructor call.

## Examples

### Invalid Examples

1. `Новый Структура("К1,К2,К3,К4", 1, 2, 3, 4)`.
2. `Новый ФиксированнаяСтруктура("К1,К2,К3,К4", 1, 2, 3, 4)`.
3. `New Structure("A,B,C,D", 1, 2, 3, 4)`.

### Valid Negative Twins

1. `Новый Структура("К1,К2,К3", 1, 2, 3)`.
2. `Новый Массив(1, 2, 3, 4)`.
3. `Новый Структура;`.
