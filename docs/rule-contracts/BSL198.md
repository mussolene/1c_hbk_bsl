## Описание диагностики

Синтаксическая конструкция **Если...Тогда...ИначеЕсли...** не должна иметь одинаковых условий.

## Примеры

```bsl
Если п = 0 Тогда
    т = 0;
ИначеЕсли п = 1 Тогда
    т = 1;
ИначеЕсли п = 1 Тогда
    т = 2;
Иначе
    т = -1;
КонецЕсли;
```

</div>

<div class="doc-lang doc-lang-en" markdown="1">

## Description

**If...Then...ElseIf...** statement should not have duplicated conditions.

## Examples

```bsl
If p = 0 Then
    t = 0;
ElseIf p = 1 Then
    t = 1;
ElseIf p = 1 Then
    t = 2;
Else
    t = -1;
EndIf;
```

## Standard And Product Decision

- Standard or product policy: `Если...Тогда...ИначеЕсли...` chains should not contain identical conditions because later duplicated branches are unreachable for the same state.
- Non-goals: Do not compare unrelated if statements or duplicated code blocks; BSL197 owns duplicated branch bodies.

## Semantic Oracle

- Checked language fact: Two or more conditions inside one `if`/`elseif` chain are structurally identical.
- Must diagnose when: the first occurrence of a condition has a later identical branch in the same chain.
- Must not diagnose when: expressions are textually similar but structurally different.
- Must not diagnose when: equal expressions are in different if statements.
- Diagnostic anchor token/range: The first duplicated condition expression, including dirty-CST parenthesis recovery when needed.

## CST Or Domain Fact Model

- CST/domain object types: `if_statement`, `elseif_clause`, child `expression`.
- Extracted attributes: structural expression key, branch order, expression range.
- Parse-error behavior: Use available CST expressions; do not fabricate diagnostics when no expression node exists.
- Shared semantic object: Conditional branch expression.

## Examples

### Invalid Examples

1. `Если П = 0 Тогда ... ИначеЕсли П = 1 Тогда ... ИначеЕсли П = 1 Тогда ... КонецЕсли;`.
2. `If A Then ... ElsIf B Then ... ElsIf B Then ... EndIf;`.
3. `Если А Тогда ... ИначеЕсли А Тогда ... КонецЕсли;`.

### Valid Negative Twins

1. Equal conditions in two separate `Если` statements.
2. `П = 1` and `П <> 1`.
3. Duplicated branch code with different conditions; BSL197 owns that case.
