## Описание диагностики

Синтаксическая конструкция **Если...Тогда...ИначеЕсли...** не должна иметь одинаковых условий.

## Примеры

```bsl
Если п = 0 Тогда
    т = 0;
ИначеЕсли п = 1 Тогда
    т = 1;
ИначеЕсли п = 1 Тогда
    т = 2;
Иначе
    т = -1;
КонецЕсли;
```

</div>

<div class="doc-lang doc-lang-en" markdown="1">

## Description

**If...Then...ElseIf...** statement should not have duplicated conditions.

## Examples

```bsl
If p = 0 Then
    t = 0;
ElseIf p = 1 Then
    t = 1;
ElseIf p = 1 Then
    t = 2;
Else
    t = -1;
EndIf;
```
