# BSL260 UnsafeFindByCode Contract

## Rule Identity

- Code: BSL260
- BSLLS compatible name: UnsafeFindByCode
- Public name/i18n key: UnsafeFindByCode / BSL260
- Default message/i18n key: RULE_MESSAGES_RU["BSL260"]
- Description/i18n key: RULE_METADATA["BSL260"].description
- Severity: WARNING
- Parameters/defaults: metadata safety is derived from object XML `CheckUnique` and `CodeSeries`.
- Rule status: parity-classified

## Standard And Product Decision

- Standard or product policy: `НайтиПоКоду()` / `FindByCode()` is unsafe when metadata does not guarantee unique whole-object codes.
- Why this diagnostic exists: code lookup can return an unexpected object if code uniqueness or numbering scope is unsafe.
- Non-goals: safe metadata, non-code lookup methods, comments/strings, and calls whose metadata root cannot be resolved.
- Keep/drop decision: keep as a BSLLS-compatible metadata correctness diagnostic.

## Semantic Oracle

- Checked language fact: a `method_call` to `НайтиПоКоду` / `FindByCode` is made on a metadata object whose code settings are unsafe.
- Must diagnose when: metadata index says the target object has non-unique codes or unsafe code series.
- Must not diagnose when: metadata is safe, missing, unrelated, or the call appears outside code.
- Diagnostic anchor token/range: method name token.
- Quick-fix target, if any: use a unique reference, safe lookup, or correct metadata settings.

## CST Or Domain Fact Model

- Parser/tree source: tree-sitter BSL CST plus cached configuration metadata index.
- CST/domain object types: `method_call`, receiver/member access text, metadata XML object settings.
- Extracted attributes: method name, receiver metadata key, `CheckUnique`, `CodeSeries`, and method-name range.
- Parse-error behavior: no CST method-call facts means no BSL260 diagnostic.
- Textual/regex behavior, only if genuinely textual: none for valid paths.

## Examples

### Invalid Examples

1. `Справочники.Товары.НайтиПоКоду("1")` when `CheckUnique=false`.
2. `Catalogs.Items.FindByCode("1")` with unsafe code series.
3. `ПланыСчетов.План.НайтиПоКоду("1")` with unsafe metadata.

### Valid Negative Twins

1. `Справочники.Товары.НайтиПоНаименованию("A")`.
2. `НайтиПоКоду` on safe whole-catalog unique codes.
3. `"Справочники.Товары.НайтиПоКоду()"` inside a string.

### Edge Examples

- Comments: ignored by CST.
- Strings: ignored by CST.
- Preprocessor: no separate semantic target.
- Multiline: method-call range comes from CST.
- Nested constructs: nested calls are checked the same way.
- BSL/SDBL variants, if relevant: SDBL is not relevant.
