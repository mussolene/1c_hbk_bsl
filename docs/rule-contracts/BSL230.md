## Standard And Product Decision

- Standard or product policy: `НачатьТранзакцию` / `BeginTransaction` and its commit/rollback counterparts must be paired in the context of one method.
- Why this diagnostic exists: transaction lifecycle split across methods or missing counterparts can leave transactions unbalanced and corrupt data consistency.
- Non-goals: proving all control-flow paths commit/rollback, validating try/catch placement, or diagnosing rollback-first ordering beyond pair absence.
- Keep/drop decision: keep as a transaction correctness diagnostic.

## Semantic Oracle

- Checked language fact: within one procedure/function, begin calls are balanced with commit calls and with rollback calls according to BSLLS pair stacks.
- Must diagnose when: a commit/rollback appears without a preceding begin in the same method, or a begin remains unmatched for either commit or rollback pair.
- Must not diagnose when: every begin has a matching commit and rollback counterpart in the same method according to the pair stacks.
- Diagnostic anchor token/range: the unmatched transaction method call.
- Quick-fix target, if any: move transaction lifecycle calls into the same method and add the missing commit/rollback counterpart.

## Examples

### Invalid Examples

1. `Процедура А()\n    НачатьТранзакцию();\nКонецПроцедуры`
2. `Процедура А()\n    ЗафиксироватьТранзакцию();\nКонецПроцедуры`
3. `Procedure A()\n    RollbackTransaction();\nEndProcedure`

### Valid Negative Twins

1. `НачатьТранзакцию();\nЗафиксироватьТранзакцию();\nОтменитьТранзакцию();`
2. `BeginTransaction();\nCommitTransaction();\nRollbackTransaction();`
3. The begin, commit, and rollback calls are all inside the same procedure/function.

### Edge Examples

- Comments: ignored by CST extraction.
- Strings: ignored by CST extraction.
- Preprocessor: not a separate semantic target.
- Multiline: call ranges come from CST/global-call facts.
- Nested constructs: calls are ordered within the containing method, not branch-sensitive.
- BSL/SDBL variants, if relevant: query text is outside this rule.
