## Standard And Product Decision

- Standard or product policy: method calls must not contain an empty trailing parameter represented by a comma before the closing parenthesis.
- Why this diagnostic exists: a trailing comma in a call usually indicates a missing argument or stale edit.
- Non-goals: commas between real arguments, commas inside strings, comments, and non-call punctuation.
- Keep/drop decision: keep as a BSLLS-compatible correctness/style diagnostic.

## Semantic Oracle

- Checked language fact: a call argument list has a comma immediately before its closing parenthesis.
- Must diagnose when: `, )` appears on one line or a line ending with a comma is followed by the closing `)` line.
- Must not diagnose when: the comma separates a real next argument, appears inside a string/comment, or belongs to ordinary text.
- Diagnostic anchor token/range: the extra comma only.
- Quick-fix target, if any: remove the extra comma or add the missing argument.

## CST Or Domain Fact Model

- Parser/tree source: physical source lines with comment stripping and string-aware same-line checks.
- CST/domain object types: textual comma facts in call argument lists.
- Extracted attributes: comma line/column, next significant code line, and closing-parenthesis adjacency.
- Parse-error behavior: malformed calls may still report a clear trailing comma; BSL001 owns broader syntax structure.
- Textual/regex behavior, only if genuinely textual: textual scan is sufficient because the diagnostic anchor is a comma token before `)`.

## Examples

### Invalid Examples

1. `Метод(Параметр,);`
2. `Метод(Параметр,\n);`
3. `Метод(Первый,\n    Второй,\n);`

### Valid Negative Twins

1. `Метод(Первый, Второй);`
2. `Метод("Комментарий", "");`
3. `// Метод(Параметр,);`

### Edge Examples

- Comments: ignored.
- Strings: commas inside string literals are ignored.
- Preprocessor: not a separate semantic target.
- Multiline: trailing comma before a next-line `)` is reported.
- Nested constructs: only the comma token is diagnosed.
- BSL/SDBL variants, if relevant: query text is outside this rule.
