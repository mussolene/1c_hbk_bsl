## Описание диагностики

Для того чтобы избежать дублирования кода, рекомендуется создавать клиент-серверные общие модули с теми процедурами и функциями, содержание которых одинаково на сервере и на клиенте. Такие процедуры и функции размещаются в общих модулях с признаками:

* Клиент (управляемое приложение)
* Сервер (флажок Вызов сервера сброшен)
* Клиент (обычное приложение)
* Внешнее соединение

Общие модули этого вида именуются с постфиксом "КлиентСервер" (англ. "ClientServer").

## Примеры

РаботаСФайламиКлиентСервер, ОбщегоНазначенияКлиентСервер, UsersClientServer

## Источники

[Стандарт: Правила создания общих модулей](https://its.1c.ru/db/v8std#content:469:hdoc:2.4)

## Description

To avoid code duplication, it is recommended to create client-server common modules with methods whose contents are the same on the server and on the client. These modules have signs:

* Client (Managed application)
* Server (ServerCall is disabled)
* Client (Ordinary application)
* External connection

Common modules of this type are named with the "ClientServer" (rus. "КлиентСервер").

## Examples

FilesClientServer, CommonClientServer, UsersClientServer

## Sources

[Standard: Rules for creating common modules (RU)](https://its.1c.ru/db/v8std#content:469:hdoc:2.4)

## Standard And Product Decision

- Standard or product policy: client-server common modules should be named so their mixed execution context is visible from the module name.
- Why this diagnostic exists: client-server common modules are callable from both sides; names without a client-server marker obscure the intended context.
- Non-goals: client-only modules covered by BSL162, global-client modules covered by BSL166, non-client-server modules, missing/unreadable XML, and other naming predicates.
- Keep/drop decision: keep as a BSLLS-compatible common-module naming diagnostic.

## Semantic Oracle

- Checked language fact: a common module is client-server and its metadata name does not contain a client-server marker.

- Must not diagnose when: XML is missing/unreadable, the module is not client-server, or the name already contains an accepted client-server marker.
