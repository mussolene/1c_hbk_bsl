## Настройка и подавление

Код `BSL###` — основной стабильный идентификатор. Совместимый псевдоним
принимается в `select`, `ignore` и совместимых блоковых комментариях.

```toml
[tool.onec-hbk-bsl]

ignore = ["UnknownPreprocessorSymbol"]
```

Подавить диагностику только на текущей строке:


```bsl
// BSLLS:UnknownPreprocessorSymbol-off
// код без этой диагностики
// BSLLS:UnknownPreprocessorSymbol-on
```

## Описание диагностики

Использование неизвестных символов препроцессора недопустимо, это может привести к различным ошибкам, в том числе логическим, когда, по какой-то причине, платформа пропустит ошибку, просто проигнорировав написанный код.

</div>

<div class="doc-lang doc-lang-en" markdown="1">

## Description

The use of unknown preprocessor symbols is unacceptable, this can lead to various errors, including logical ones, when, for some reason, the platform will miss an error by simply ignoring the written code.

</div>
