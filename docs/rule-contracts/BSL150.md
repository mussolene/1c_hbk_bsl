## Настройка и подавление

Код `BSL###` — основной стабильный идентификатор. Совместимый псевдоним
принимается в `select`, `ignore` и совместимых блоковых комментариях.

```toml
[tool.onec-hbk-bsl]
select = ["BSL150"]
ignore = ["BadWords"]
```

Подавить диагностику только на текущей строке:

```bsl
Значение = "пример";  // noqa: BSL150
Значение = "пример";  // bsl-disable: BSL150
```

Отключить правило для блока или всего файла:

```bsl
// BSLLS:BadWords-off
// код без этой диагностики
// BSLLS:BadWords-on
```

## Configuration and suppression

`BSL###` is the primary stable identifier. The compatible alias is accepted
in `select`, `ignore`, and compatible block suppression comments.


Suppress the diagnostic on the current line:

```bsl

Value = "example";  // bsl-disable: BSL150
```

Disable the rule for a block or the whole file:

```bsl
// BSLLS:BadWords-off
// code without this diagnostic
// BSLLS:BadWords-on
```

## Описание диагностики
В тексте модулей не должны встречаться запрещенные слова.
Список запрещенных слов задается регулярным выражением.
Поиск производится без учета регистра символов.

**Примеры настройки:**

"редиска|лопух|экзистенциальность"

"ло(х|шара|шпед)"

</div>

<div class="doc-lang doc-lang-en" markdown="1">

## Description
Software modules should not contain prohibited words.
The list of forbidden words is set by a regular expression.
The search is case-insensitive.

**For example:**

"singularity|avada kedavra|Donald"

"transcenden(tal|ce)"
