## Standard And Product Decision

- Standard or product policy: filesystem access requires security review because it may read, write, copy, move, or delete protected data.
- Why this diagnostic exists: direct filesystem APIs and filesystem-related objects are security-sensitive and should be audited.
- Non-goals: member calls with the same method names, call-looking text in strings/comments, or unrelated identifiers containing filesystem words.
- Keep/drop decision: keep as a CST-backed security audit diagnostic.

- Must not diagnose when: the same text appears in a string/comment, the method is called as a member, or the constructed/called name is not in the configured set.

- Quick-fix target, if any: none; manual security review is required.
