## Описание диагностики

Недопустимо перехватывать любые исключения, бесследно для системного администратора.

*Неправильно*

```bsl
Попытка
    // код, приводящий к вызову исключения
    ....
Исключение // перехват любых исключений
КонецПопытки;

```

Как правило, подобная конструкция скрывает реальную проблему, которую впоследствии невозможно диагностировать.

*Правильно*

```bsl
Попытка
    // код, приводящий к вызову исключения
    ....
Исключение
    // Пояснение причин перехвата всех исключений "незаметно" от пользователя.
    // ....
    // И запись события в журнал регистрации для системного администратора.
    ЗаписьЖурналаРегистрации(НСтр("ru = 'Выполнение операции'"),
       УровеньЖурналаРегистрации.Ошибка,,,
       ПодробноеПредставлениеОшибки(ИнформацияОбОшибке()));
КонецПопытки;
```

## Description

It is unacceptable to catch any exception, without any trace for system administrator.

*Incorrect*

```bsl
Try
    // code causing exception
    ....
Raise // catch any exception
EndTry;

```

As a rule, such a design hides a real problem, which is subsequently impossible to diagnose.

*Correct*

```bsl
Try
    // code causing exception
    ....
Raise
    // Explanation why catching all exceptions untraceable for enduser.
    // ....
    // Write to log for system administrator.
    WriteLogEvent(NStr("en = 'Action'"),
       EventLogLevel.Error,,,
       DetailErrorDescription(ErrorInfo()));
EndTry;
```

- Standard or product policy: caught exceptions must not disappear without executable handling or logging.

## Semantic Oracle

- Checked language fact: a parsed `Попытка ... Исключение ... КонецПопытки` statement has no executable code after `Исключение`.
- Must diagnose when: the exception handler contains only whitespace/comments before `КонецПопытки`.
- Must not diagnose when: the exception handler contains executable code, or the code is not an exception handler.
- Diagnostic anchor token/range: `Исключение` / `Except` keyword span.
- Quick-fix target, if any: add logging/handling code or remove the empty catch block.
