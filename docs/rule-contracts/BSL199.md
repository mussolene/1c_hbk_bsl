# BSL199 IfElseIfEndsWithElse Contract

## Rule Identity

- Code: BSL199
- BSLLS compatible name: IfElseIfEndsWithElse
- Rule status: implemented

## Standard And Product Decision

- Standard or product policy: An `Если...Тогда...ИначеЕсли...` chain should end with `Иначе` as defensive programming.
- Non-goals: Do not report plain `Если...Тогда...КонецЕсли` without `ИначеЕсли`.

## Semantic Oracle

- Checked language fact: An if statement contains at least one `elseif_clause` and no `else_clause`.
- Must diagnose when: an if chain has one or more `ИначеЕсли` branches and no final `Иначе`.
- Must diagnose when: the same shape appears in English syntax.
- Must not diagnose when: the if chain contains a final `Иначе`/`Else`.
- Must not diagnose when: there is no `ИначеЕсли`/`ElsIf`.
- Diagnostic anchor token/range: The final `КонецЕсли`/`EndIf` token, matching BSLLS stop-token behavior.

## CST Or Domain Fact Model

- CST/domain object types: `if_statement`, child `elseif_clause`, child `else_clause`, final `ENDIF_KEYWORD`.
- Extracted attributes: presence of elseif branch, presence of else branch, final endif range.
- Parse-error behavior: Do not report if the CST cannot prove the final endif token.
- Shared semantic object: Conditional statement branch shape.

## Examples

### Invalid Examples

1. `Если А Тогда ... ИначеЕсли Б Тогда ... КонецЕсли;`.
2. `If A Then ... ElsIf B Then ... EndIf;`.
3. `Если ТипЗнч(П) = Тип("Строка") Тогда ... ИначеЕсли П = Неопределено Тогда ... КонецЕсли;`.

### Valid Negative Twins

1. `Если А Тогда ... КонецЕсли;`.
2. `Если А Тогда ... ИначеЕсли Б Тогда ... Иначе ... КонецЕсли;`.
3. Equal branch conditions are handled by BSL198, not by this rule.
