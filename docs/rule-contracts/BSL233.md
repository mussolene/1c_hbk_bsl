## Настройка и подавление

Код `BSL###` — основной стабильный идентификатор. Совместимый псевдоним
принимается в `select`, `ignore` и совместимых блоковых комментариях.

```toml
[tool.onec-hbk-bsl]
select = ["BSL233"]
ignore = ["PublicMethodsDescription"]
```

Подавить диагностику только на текущей строке:

```bsl
Значение = "пример";  // noqa: BSL233
Значение = "пример";  // bsl-disable: BSL233
```

Отключить правило для блока или всего файла:

```bsl
// BSLLS:PublicMethodsDescription-off
// код без этой диагностики
// BSLLS:PublicMethodsDescription-on
```

Suppress the diagnostic on the current line:


## Описание диагностики
Все экспортные методы, располагающиеся в области `ПрограмнныйИнтерфейс`, должны иметь описание.
