- Rule status: verified

## Standard And Product Decision

- Standard or product policy: common module names should avoid generic redundant words such as `Модуль`.
- Why this diagnostic exists: words like `Модуль` add no useful semantic meaning to common-module names and make the API surface noisier.
- Non-goals: execution-context suffix rules, cached/global/client/server-call naming, missing/unreadable XML, and non-common modules.
- Keep/drop decision: keep as a BSLLS-compatible common-module naming diagnostic.

## Semantic Oracle

- Checked language fact: a common module metadata name contains a forbidden generic word.
- Must diagnose when: sibling common-module XML exists and the module name contains a forbidden word from the supported BSLLS-compatible set, including `Модуль`.
- Must not diagnose when: XML is missing/unreadable, the metadata is not a common module, or the module name contains no forbidden generic words.
- Diagnostic anchor token/range: first character of the first non-empty/non-BOM module line, line character 0-1.
- Quick-fix target, if any: rename the common module to remove the generic word.

## CST Or Domain Fact Model

- Parser/tree source: XML metadata for common-module name; BSL text is used for the diagnostic anchor.
- CST/domain object types: common-module XML snapshot and first non-empty module line.
- Extracted attributes: module name, forbidden-word match, and anchor line.
- Parse-error behavior: BSL parse errors do not affect this XML-driven naming rule.
- Textual/regex behavior, only if genuinely textual: XML tags and forbidden-word matching are textual metadata conventions.

## Examples

### Invalid Examples

1. Common module named `ОбменДаннымиМодуль`.
2. Common module named `МодульИнтеграции`.
3. Common module name containing a supported forbidden generic word.

### Valid Negative Twins

1. Common module named `ОбменДанными`.
2. Common module named `ИнтеграцияКлиент`.
3. Non-common-module metadata name containing `Модуль`.

- Nested constructs: BSL procedures/functions do not affect this rule.
- BSL/SDBL variants, if relevant: SDBL is not relevant.
