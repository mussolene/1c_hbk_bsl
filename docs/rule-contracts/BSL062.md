## Настройка и подавление

Код `BSL###` — основной стабильный идентификатор. Совместимый псевдоним
принимается в `select`, `ignore` и совместимых блоковых комментариях.

```toml
[tool.onec-hbk-bsl]
select = ["BSL062"]
ignore = ["UnusedParameters"]
```

Подавить диагностику только на текущей строке:

```bsl
Значение = "пример";  // noqa: BSL062
Значение = "пример";  // bsl-disable: BSL062
```

Отключить правило для блока или всего файла:

```bsl
// BSLLS:UnusedParameters-off
// код без этой диагностики
// BSLLS:UnusedParameters-on
```

## Configuration and suppression

`BSL###` is the primary stable identifier. The compatible alias is accepted
in `select`, `ignore`, and compatible block suppression comments.

```toml
[tool.onec-hbk-bsl]

ignore = ["UnusedParameters"]
```

Suppress the diagnostic on the current line:

```bsl
Value = "example";  // noqa: BSL062
Value = "example";  // bsl-disable: BSL062
```

Disable the rule for a block or the whole file:

```bsl
// BSLLS:UnusedParameters-off
// code without this diagnostic
// BSLLS:UnusedParameters-on
```

## Описание диагностики
Методы не должны содержать неиспользуемых параметров.

## Примеры

```bsl
Функция СложитьДваЧисла(Знач ПервоеЧисло, Знач ВтороеЧисло, Знач ЛишнийПараметр)

    Возврат ПервоеЧисло + ВтороеЧисло;

КонецФункции
```

</div>

<div class="doc-lang doc-lang-en" markdown="1">

## Description
Methods shouldn't contain unused parameters.

## Examples

```bsl
Function AddTwoNumbers(Val FirstValue, Val SecondValue, Val UnusedParameter)

    Return FirstValue + SecondValue;

EndFunction
```
