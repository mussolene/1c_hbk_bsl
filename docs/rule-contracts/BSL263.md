## Standard And Product Decision

- Standard or product policy: `Для каждого` / `For Each` loops should use their iterator in the loop body; otherwise the loop is redundant or the body is incomplete.
- Why this diagnostic exists: an unused iterator usually means an accidental collection-level call in a per-item loop or dead iteration overhead.
- Non-goals: proving side effects of the collection expression, optimizing loops that intentionally repeat a fixed action, or diagnosing ordinary `Для` numeric loops.
- Keep/drop decision: keep as a BSLLS-compatible correctness/clumsy diagnostic.

## Semantic Oracle

- Checked language fact: a `for_each_statement` has an iterator identifier that is not referenced inside the loop body.
- Must diagnose when: the iterator declared after `Каждого` / `Each` is absent from all body identifier references.
- Must not diagnose when: the iterator is used anywhere in the loop body, the statement is not a `for_each_statement`, or the iterator name is a module-level variable intentionally skipped by the current compatibility policy.
- Diagnostic anchor token/range: the iterator identifier.
- Quick-fix target, if any: use the iterator in the loop body or remove the useless loop.

## Examples

### Invalid Examples

1. `Для каждого Элемент Из Коллекция Цикл ВыполнитьДействие(Коллекция); КонецЦикла;`
2. `For Each Item In Items Do DoWork(Items); EndDo;`
3. A non-empty loop body that reads only the collection expression and never reads the iterator.

### Valid Negative Twins

1. `Для каждого Элемент Из Коллекция Цикл ВыполнитьДействие(Элемент); КонецЦикла;`
2. `For Each Item In Items Do DoWork(Item); EndDo;`
3. A loop where the iterator name is a module-level variable under the current compatibility skip policy.

### Edge Examples

- Comments: identifier-looking text in comments is not a CST identifier usage.
- Strings: identifier-looking text in strings is not a CST identifier usage.
- Preprocessor: not a separate semantic target.
- Multiline: supported because the CST body is walked structurally.
- Nested constructs: nested body nodes count as iterator usage when they contain the iterator identifier.
- BSL/SDBL variants, if relevant: query text is outside this rule.
