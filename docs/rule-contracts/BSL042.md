## Описание диагностики

Программные модули не должны иметь неиспользуемых процедур и функций. Диагностика умеет пропускать `подключаемые методы`, имеющие префиксы, указанные в параметре диагностики.

## Источники

## Description

Modules should not have unused procedures and functions. Diagnostics can skip `attachable methods` that have prefixes specified in the diagnostic parameter.
