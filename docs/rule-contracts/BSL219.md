## Описание диагностики

Все переменные модулей, а также все экспортируемые переменные должны иметь комментарии.

## Примеры

Неправильно:

```bsl
Перем Контекст;
```

Правильно:

```bsl
Перем Контекст; // Некое подробное описание, которое объясняет назначение переменной

// Некое подробное описание, которое объясняет назначение переменной
Перем Контекст;
```

## Description

All module variables and export variables must have comments.

## Examples

Incorrect:

```bsl
Var Context;
```

Correct:

```bsl
Var Context; // Detailed description that explains the purpose of the variable

// Detailed description that explains the purpose of the variable
Var Context;
```
