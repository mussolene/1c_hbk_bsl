## Настройка и подавление

Код `BSL###` — основной стабильный идентификатор. Совместимый псевдоним
принимается в `select`, `ignore` и совместимых блоковых комментариях.

```toml
[tool.onec-hbk-bsl]
select = ["BSL189"]
ignore = ["ForbiddenMetadataName"]
```

Все три семейства подавлений работают для текущей строки и диапазона.
Если открывающий комментарий стоит после кода, он действует только на
эту строку. Используйте любой один вариант:

- `noqa`:

```bsl
Значение = "пример";  // noqa: BSL189
```

- `bsl-disable` (совместимый вариант):

```bsl
Значение = "пример";  // bsl-disable: BSL189
```

- совместимый `BSLLS`-вариант:

```bsl
Значение = "пример";  // BSLLS:ForbiddenMetadataName-off
```

Если тот же открывающий комментарий стоит на отдельной строке, он
начинает диапазон. Закройте его парным маркером того же семейства:

```bsl
// noqa: BSL189
// код без этой диагностики
// noqa-enable: BSL189

// bsl-disable: BSL189
// код без этой диагностики
// bsl-enable: BSL189

// BSLLS:ForbiddenMetadataName-off
// код без этой диагностики
// BSLLS:ForbiddenMetadataName-on
```

Чтобы отключить правило до конца файла, не добавляйте закрывающий
`noqa-enable`, `bsl-enable` или `BSLLS:…-on`.

Открывающий и закрывающий маркеры должны принадлежать одному семейству.

## Configuration and suppression

`BSL###` is the primary stable identifier. The compatible alias is accepted
in `select`, `ignore`, and compatible block suppression comments.

```toml
[tool.onec-hbk-bsl]
select = ["BSL189"]
ignore = ["ForbiddenMetadataName"]
```

All three suppression families support both a current line and a range.
When an opening comment follows code, it affects only that line. Use any
one form:

- `noqa`:

```bsl
Value = "example";  // noqa: BSL189
```

- `bsl-disable`:

```bsl
Value = "example";  // bsl-disable: BSL189
```

- compatible `BSLLS` form:

```bsl
Value = "example";  // BSLLS:ForbiddenMetadataName-off
```

When the same opening comment is on a line by itself, it starts a range.
Close it with the matching marker from the same family:

```bsl
// noqa: BSL189
// code without this diagnostic
// noqa-enable: BSL189

// bsl-disable: BSL189
// code without this diagnostic
// bsl-enable: BSL189

// BSLLS:ForbiddenMetadataName-off
// code without this diagnostic
// BSLLS:ForbiddenMetadataName-on
```

To disable the rule until the end of the file, omit the closing
`noqa-enable`, `bsl-enable`, or `BSLLS:…-on` marker.

Opening and closing markers must belong to the same family.

## Описание диагностики

Запрещено использовать имена объектов метаданных (и их реквизитов и табличных частей), которые применяются при именовании таблиц запросов (например Документ, Справочник).

Использование таких имен может приводить к ошибкам при исполнении запроса, а кроме того, затрудняют использование конструктора запросов и снижают наглядность текста запроса.

## Примеры

Плохое наименование
- `Справочник.Справочник`
- `Справочник.МойСправочник.Реквизит.Документ`
- `РегистрСведений.МойРегистрСведений.Измерение.Документы`

## Description

It is forbidden to use the names of metadata objects (and their attributes and tabular sections), which are used when naming query tables (for example, Document, Catalog).

Using such names can lead to errors in the execution of the query, and also make it difficult to use the query designer and reduce the clarity of the query text.

## Examples

Wrong name
- `Catalog.Catalog`
- `Catalog.MyCatalog.Attribute.Document`
- `InformationRegister.MyRegister.Dimension.Documents`
