## Описание диагностики

При конкатенации строк разработчик может ошибочно написать код вида Строка + + Строка2, т.е. второй плюс платформа распознает как унарный и попытается выолнить преобразование к числу, что в большинстве случаев приведет к ошибке исполнения

</div>

<div class="doc-lang doc-lang-en" markdown="1">

## Description

When concatenating strings, a developer may mistakenly write code String + + String2, i.e. the second plus, the platform recognizes as unary and tries to cast to a number, which in most cases will lead to a runtime exception

</div>
