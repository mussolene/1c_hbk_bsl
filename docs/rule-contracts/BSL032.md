## Описание диагностики

`Функция` отличается от `Процедуры` только тем, что обязательно возвращает значение и может быть использована в выражениях.

Исходя из описанного выше утверждения, `функция` не содержащая возврата, сама по себе является ошибочной. Необходимо внести исправления

- реализовать возврат значения, если реализованный метод все-таки является функцией
- переписать функцию на процедуру, если возврат значения не предусматривается

</div>

<div class="doc-lang doc-lang-en" markdown="1">

## Description

`Function` differs from a `Procedure` only that it necessarily returns a value and can be used in expressions.

Based on the above-mentioned, a `function` which does not contain a return is itself erroneous. Corrections required:

- implement return if the implemented method is a function
- rewrite function to procedure if return is not needed

</div>

## Standard And Product Decision

- Standard or product policy: a function must return a value; otherwise it should be a procedure.
- Why this diagnostic exists: functions without `Возврат`/`Return` create unpredictable call behavior and usually indicate a wrong method kind.
- Non-goals: proving all paths return, checking returned primitive values, or reporting procedures that return values; those are owned by related rules.
- Keep/drop decision: keep as a BSLLS-compatible function-contract diagnostic.

## Semantic Oracle

- Checked language fact: a parsed function body contains no return statement.
- Must diagnose when: a procedure/function fact is a function and no `Возврат`/`Return` statement exists in its body.
- Must not diagnose when: the method is a procedure, the function has at least one return statement, or method facts are unavailable.
- Diagnostic anchor token/range: function name in the declaration line.
- Quick-fix target, if any: add a return statement or convert the function to a procedure.

## CST Or Domain Fact Model

- Parser/tree source: parsed procedure/function facts from the document model.
- CST/domain object types: `ProcedureModel`/`ProcInfo` with kind, start/end indices, and body lines.
