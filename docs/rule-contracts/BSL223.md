## Описание диагностики

Не рекомендуется в конструкторе структуры использовать конструкторы других объектов, если эти конструкторы принимают параметры. В частности в конструкторе одной структуры не рекомендуется создавать другие структуры с объявлением значений свойств.

## Примеры

Неправильно

```bsl
НоменклатураСервер.ЗаполнитьСлужебныеРеквизитыПоНоменклатуреВКоллекции(
  Объект.Товары,
  Новый Структура(
  "ЗаполнитьПризнакХарактеристикиИспользуются,
  |ЗаполнитьПризнакТипНоменклатуры, ЗаполнитьПризнакВариантОформленияПродажи",
   Новый Структура("Номенклатура", "ХарактеристикиИспользуются"),
   Новый Структура("Номенклатура", "ТипНоменклатуры"),
   Новый Структура("Номенклатура", "ВариантОформленияПродажи")
  )
 );
```

Правильно

```bsl
ПараметрыЗаполненияРеквизитов = Новый Структура;
ПараметрыЗаполненияРеквизитов.Вставить("ЗаполнитьПризнакХарактеристикиИспользуются",
                                                          Новый Структура("Номенклатура", "ХарактеристикиИспользуются"));
ПараметрыЗаполненияРеквизитов.Вставить("ЗаполнитьПризнакТипНоменклатуры",
                                                          Новый Структура("Номенклатура", "ТипНоменклатуры"));
НоменклатураСервер.ЗаполнитьСлужебныеРеквизитыПоНоменклатуреВКоллекции(Объект.Товары,
                                                          ПараметрыЗаполненияРеквизитов);
```

## Description

It is not recommended to use constructors of other objects in the structure constructor if these constructors accept parameters. In particular, in the constructor of one structure it is not recommended to create other structures with the declaration of property values.

## Examples

Incorrect

```bsl
GoodsServer.MakeGoods(
  Object.Products,
  New Structure(
  "CharacteristicsUsed,
  |Type, Variant",
   New Structure("Good", "CharacteristicsUsed"),
   New Structure("Good", "Type"),
   New Structure("Good", "Variant")
  )
 );
```

Correct

```bsl
Parameters = New Structure;
Parameters.Вставить("CharacteristicsUsed", New Structure("Good", "CharacteristicsUsed"));
Parameters.Вставить("Type",                New Structure("Good", "Type"));
Parameters.Вставить("Variant",             New Structure("Good", "Variant"));
GoodsServer.MakeGoods(Object.Products,     Parameters);
```

## Standard And Product Decision

- Standard or product policy: constructors with parameters should not be nested inside a `Структура` / `Structure` declaration with values.
- Why this diagnostic exists: nested parameterized constructors inside structure declarations make call sites dense and hard to read; temporary variables or incremental `Вставить` calls are clearer.
- Non-goals: banning all structure constructors, banning nested parameterless constructors, or checking ordinary nested constructors outside structure declaration values.
- Keep/drop decision: keep as a BSLLS-compatible readability/design diagnostic.

## Semantic Oracle

- Checked language fact: an outer `Новый Структура` / `New Structure` or fixed-structure constructor with values contains at least one nested `new_expression` with one or more constructor arguments in its value arguments.
- Must diagnose when: the outer structure constructor has key/value arguments and any value argument subtree contains `Новый <Тип>(...)` / `New <Type>(...)` with at least one argument.
- Must not diagnose when: the outer constructor has only keys/no values, nested constructors have no arguments, or the nested constructor appears outside the outer structure value arguments.
- Diagnostic anchor token/range: the whole outer structure constructor expression.
- Quick-fix target, if any: create nested values separately and pass variables, or fill the structure incrementally.

## CST Or Domain Fact Model

- Parser/tree source: BSL CST `new_expression` nodes via the light call pool.
- CST/domain object types: outer structure/fixed-structure `new_expression`, nested `new_expression`, constructor arguments, and identifier/type node.
- Extracted attributes: outer type name, outer argument count, nested constructor argument count, and outer constructor range.
- Parse-error behavior: malformed constructor syntax is owned by BSL001; this rule requires extractable CST constructor arguments.
- Textual/regex behavior, only if genuinely textual: none for valid CST paths.
