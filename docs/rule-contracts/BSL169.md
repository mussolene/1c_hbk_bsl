- Публичный идентификатор `BSL169` и псевдоним `CompilationDirectiveLost` стабильны.
- Правило сообщает о случаях, описанных на этой странице.

## Настройка и подавление

Код `BSL###` — основной стабильный идентификатор. Совместимый псевдоним
принимается в `select`, `ignore` и совместимых блоковых комментариях.

```toml
[tool.onec-hbk-bsl]
select = ["BSL169"]
ignore = ["CompilationDirectiveLost"]
```

Подавить диагностику только на текущей строке:

```bsl
Значение = "пример";  // noqa: BSL169
Значение = "пример";  // bsl-disable: BSL169
```

Отключить правило для блока или всего файла:

```bsl
// BSLLS:CompilationDirectiveLost-off
// код без этой диагностики
// BSLLS:CompilationDirectiveLost-on
```


```bsl

// BSLLS:CompilationDirectiveLost-on
```

## Описание диагностики
У всех методов управляемых форм и команд должны быть указаны директивы компиляции.

## Примеры

#### Неправильно:
```bsl
Процедура ПриСозданииНаСервере()
...
КонецПроцедуры
```

#### Правильно:
```bsl
&НаСервере
Процедура ПриСозданииНаСервере()
...
КонецПроцедуры
```

## Description
All methods of managed forms and commands must have compilation directives.

## Examples

#### Incorrect:
```bsl
Procedure OnCreateAtServer()
...
EndProcedure
```

#### Correct:
```bsl
&AtServer
Procedure OnCreateAtServer()
...
EndProcedure
```
