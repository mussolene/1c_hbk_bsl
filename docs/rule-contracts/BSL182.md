# BSL182 ExcessiveAutoTestCheck Contract

## Rule Identity

- Code: BSL182
- BSLLS compatible name: ExcessiveAutoTestCheck
- Rule status: implemented

## Standard And Product Decision

- Standard or product policy: The old automated-testing interaction standard was cancelled; form/object code should not short-circuit execution only because the `АвтоТест`/`AutoTest` parameter is present.
- Non-goals: Do not report business logic that checks the same string but executes additional actions before returning.

## Semantic Oracle

- Checked language fact: An `if`/`elseif` branch checks `.Свойство("АвтоТест")`, `.Property("AutoTest")`, `= "АвтоТест"`, or `= "AutoTest"` and the branch body contains only `Возврат`/`Return`.
- Must diagnose when: the checked branch body has exactly one return statement.
- Must diagnose when: the condition is in the first `Если` branch or in an `ИначеЕсли` branch.
- Must not diagnose when: the branch body contains another statement in addition to return.
- Must not diagnose when: the same text is inside strings or comments.
- Diagnostic anchor token/range: The whole `if`/`elseif` branch construct reported by BSLLS.

## CST Or Domain Fact Model

- CST/domain object types: `if_statement`, `elseif_clause`, child `expression`, child `return_statement`.
- Extracted attributes: branch expression text, branch body statement nodes, branch start/end range.
- Parse-error behavior: Do not report if the CST branch shape cannot prove an expression and a single return body.
- Shared semantic object: AutoTest compatibility branch.

## Examples

### Invalid Examples

1. `Если Параметры.Свойство("АвтоТест") Тогда Возврат; КонецЕсли;`.
2. `Если ДанныеЗаполнения = "АвтоТест" Тогда Возврат; КонецЕсли;`.
3. `If Parameters.Property("AutoTest") Then Return; EndIf;`.

### Valid Negative Twins

1. `Если Перечень.Свойство("АвтоТест") Тогда Перечень.Удалить("АвтоТест"); Возврат; КонецЕсли;`.
2. `Текст = "Параметры.Свойство(""АвтоТест"")";`.
3. `// Если Параметры.Свойство("АвтоТест") Тогда`.
