# BSL179 DeprecatedTypeManagedForm Contract

## Rule Identity

- Code: BSL179
- BSLLS compatible name: DeprecatedTypeManagedForm
- Rule status: implemented

## Standard And Product Decision

- Standard or product policy: Since platform 8.3.14 the `УправляемаяФорма`/`ManagedForm` type name is deprecated in favor of `ФормаКлиентскогоПриложения`.
- Non-goals: Do not diagnose arbitrary string literals or user methods whose names merely contain `Тип`/`Type`.

## Semantic Oracle

- Checked language fact: A global `Тип`/`Type` call receives the deprecated managed-form type string.
- Must diagnose when: ordinary code calls `Тип("УправляемаяФорма")` or `Type("ManagedForm")`.
- Must diagnose when: the call appears inside a larger expression such as comparison with another type.
- Must not diagnose when: the text is inside a comment or string literal.
- Must not diagnose when: the method name is only a prefix of a longer identifier.
- Diagnostic anchor token/range: The deprecated string argument token.

## CST Or Domain Fact Model

- CST/domain object types: masked source line, global `Тип`/`Type` call token.
- Extracted attributes: deprecated string literal, line, start column, end column.
- Parse-error behavior: Line-local complete calls may still be reported in otherwise broken files.
- Shared semantic object: Deprecated platform type-name reference.

## Examples

### Invalid Examples

1. `Если Тип(Форма) = Тип("УправляемаяФорма") Тогда`.
2. `If Type(Form) = Type("ManagedForm") Then`.
3. `Тип("УправляемаяФорма");`.

### Valid Negative Twins

1. `Текст = "Тип(""УправляемаяФорма"")";`.
2. `// Если Тип(Форма) = Тип("УправляемаяФорма") Тогда`.
3. `ТипФормы("УправляемаяФорма");`.
