- Rule status: verified

## Standard And Product Decision

- Standard or product policy: expression line breaks should put arithmetic/logical operators at the beginning of the continuation line, and closing call parentheses/statement separators should not start a separate line under the default policy.
- Why this diagnostic exists: line-end operators and malformed continuation starts reduce readability and conflict with the BSL formatting standard.
- Non-goals: full expression reformatting, indentation alignment, query text formatting, or changing team-specific BSLLS parameter defaults at runtime.
- Keep/drop decision: keep as a BSLLS-compatible line-style diagnostic.

## Semantic Oracle

- Checked language fact: a physical source line starts with a forbidden continuation token or ends with a forbidden operator token outside comments and string literals.
- Must diagnose when: code starts with `)`, `;`, `, <nonspace>`, or `);`, or code ends with `И`, `ИЛИ`, `AND`, `OR`, `+`, `-`, `/`, `%`, or `*`.
- Must not diagnose when: the token is inside a string/comment, the line before a query text block is intentionally skipped to avoid high-volume query-building noise, or no configured edge token is present.
- Diagnostic anchor token/range: the offending edge token.
- Quick-fix target, if any: move the operator to the beginning of the continuation line or move the closing punctuation to the previous argument line.

## Examples

### Invalid Examples

1. `Сумма = Первая +\n    Вторая;`
2. `Если Условие1 И\n    Условие2 Тогда`
3. `Метод(Первый\n    , Второй);`

### Valid Negative Twins

1. `Сумма = Первая\n    + Вторая;`
2. `Если Условие1\n    И Условие2 Тогда`
3. `Метод(Первый,\n    Второй);`

### Edge Examples

- Comments: suffix comments are excluded from edge-token matching.
- Strings: operators inside string literals are ignored.
- Preprocessor: not a separate semantic target.
- Multiline: checked per physical line.
- Nested constructs: not relevant; this is not an AST expression rule.
- BSL/SDBL variants, if relevant: query text is not inspected as ordinary BSL line-break code.
