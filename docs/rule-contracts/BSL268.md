## Настройка и подавление

Код `BSL###` — основной стабильный идентификатор. Совместимый псевдоним
принимается в `select`, `ignore` и совместимых блоковых комментариях.

```toml
[tool.onec-hbk-bsl]
select = ["BSL268"]
ignore = ["UsingFindElementByString"]
```

Все три семейства подавлений работают для текущей строки и диапазона.
Если открывающий комментарий стоит после кода, он действует только на
эту строку. Используйте любой один вариант:

- `noqa`:

```bsl
Значение = "пример";  // noqa: BSL268
```

- `bsl-disable` (совместимый вариант):

```bsl
Значение = "пример";  // bsl-disable: BSL268
```

- совместимый `BSLLS`-вариант:

```bsl
Значение = "пример";  // BSLLS:UsingFindElementByString-off
```

Если тот же открывающий комментарий стоит на отдельной строке, он
начинает диапазон. Закройте его парным маркером того же семейства:

```bsl
// noqa: BSL268
// код без этой диагностики
// noqa-enable: BSL268

// bsl-disable: BSL268
// код без этой диагностики
// bsl-enable: BSL268

// BSLLS:UsingFindElementByString-off
// код без этой диагностики
// BSLLS:UsingFindElementByString-on
```

Чтобы отключить правило до конца файла, не добавляйте закрывающий
`noqa-enable`, `bsl-enable` или `BSLLS:…-on`.

Открывающий и закрывающий маркеры должны принадлежать одному семейству.

## Configuration and suppression

`BSL###` is the primary stable identifier. The compatible alias is accepted
in `select`, `ignore`, and compatible block suppression comments.

```toml
[tool.onec-hbk-bsl]
select = ["BSL268"]
ignore = ["UsingFindElementByString"]
```

All three suppression families support both a current line and a range.
When an opening comment follows code, it affects only that line. Use any
one form:

- `noqa`:

```bsl
Value = "example";  // noqa: BSL268
```

- `bsl-disable`:

```bsl
Value = "example";  // bsl-disable: BSL268
```

- compatible `BSLLS` form:

```bsl
Value = "example";  // BSLLS:UsingFindElementByString-off
```

When the same opening comment is on a line by itself, it starts a range.
Close it with the matching marker from the same family:

```bsl
// noqa: BSL268
// code without this diagnostic
// noqa-enable: BSL268

// bsl-disable: BSL268
// code without this diagnostic
// bsl-enable: BSL268

// BSLLS:UsingFindElementByString-off
// code without this diagnostic
// BSLLS:UsingFindElementByString-on
```

To disable the rule until the end of the file, omit the closing
`noqa-enable`, `bsl-enable`, or `BSLLS:…-on` marker.

Opening and closing markers must belong to the same family.

## Описание диагностики

Правило находит использование методов `НайтиПоНаименованию`, `НайтиПоКоду` или `НайтиПоНомеру` с указанием конкретных и
уникальных номеров, кодов и названий элементов или документов.
Скорее всего, подобный код не будет работать в других ИБ, что приведет к ошибкам выполнения.
Возможно, в финальный код попал тестовый код, что также не рекомендовано.

Константные значения данных из ИБ рекомендуется указывать в константах ИБ, предопределенных элементах метаданных.

## Примеры

Неправильно:
```bsl
Должность = Справочники.Должности.НайтиПоНаименованию("Ведущий бухгалтер");
```
или
```bsl
Должность = Справочники.Должности.НайтиПоКоду("00-0000001");
```

или

```bsl
ОбъектНазначения = Документы.ПередачаТоваровМеждуОрганизациями.НайтиПоНомеру("0000-000001", ТекущаяДата());
```

Допустимо использование:
```bsl
Справочники.Валюты.НайтиПоКоду(ТекущиеДанные.КодВалютыЦифровой);
```
```bsl
Справочники.КлассификаторБанков.НайтиПоКоду(СведенияОБанке.БИК);
```

```bsl
Документы.Реализация.НайтиПоНомеру(НомерДокумента);
```

## Description

The rule finds the use of the `FindByName`, `FindByCode` or `FindByNumber` methods using specific numbers, codes and names of elements or documents.
Similar code may not work correctly in other databases.
Often such code is test code included in the release version, which is also not recommended.

It is recommended to specify constant data values ​​from the database in "Сonstants" or predefined metadata elements.

## Examples

Incorrect:
```bsl
Position = Catalogs.Positions.FindByName("Senior Accountant");
```
or
```bsl
Position = Catalogs.Positions.FindByCode("00-0000001");
```

or

```bsl
Object = Documents.Invoice.FindByNumber("0000-000001", CurrentDate());
```

Acceptable use:
```bsl
Catalogs.Currencies.FindByCode(CurrentData.CurrencyCodeDigital);
```
```bsl
Catalogs.BankClassifier.FindByCode(BankDetails.BIK);
```

```bsl
Documents.Invoice.FindByNumber(Number);
```
