- Parameters/defaults: `allowOneliner=true`, `allowedMethodNames=НСтр,NStr,ПредопределенноеЗначение,PredefinedValue`.
- Rule status: verified

## Standard And Product Decision

- Standard or product policy: method and constructor parameters should stay readable; complex nested calls inside multiline argument lists should be extracted to local variables.
- Why this diagnostic exists: multiline parameter lists with nested method or constructor calls create avoidable cognitive load and obscure argument intent.
- Non-goals: reporting compact one-line calls, calls whose only nested method names are explicitly allowed, or ordinary literals/property access in arguments.
- Keep/drop decision: keep as a BSLLS-compatible readability diagnostic.

## Semantic Oracle

- Checked language fact: a method call, function call, or constructor call has a multiline parameter list and at least one argument contains a non-allowed nested call or nested constructor with parameters.
- Must diagnose when: a call/new expression spans multiple lines and any top-level argument spanning multiple lines contains a nested method call, function call, or parameterized constructor other than the allowed names.
- Must not diagnose when: the whole call is one line, nested calls are only `НСтр`/`NStr`/`ПредопределенноеЗначение`/`PredefinedValue`, the nested expression is not in a multiline argument, or the syntax tree is invalid.
- Diagnostic anchor token/range: the outer call or constructor name token.
- Quick-fix target, if any: extract the nested call into a local variable before the outer call.

## CST Or Domain Fact Model

- Parser/tree source: tree-sitter BSL CST through the method-contract runtime rule.

- Parse-error behavior: structural CST path skips invalid trees; BSL001 owns syntax errors.

## Examples

### Invalid Examples

1. `Метод(` with an argument spanning multiple lines that contains `ДругойМетод(...)`.
2. `Новый Структура(` with a multiline value argument `Новый Структура(...)`.
3. `Коллекция.Вставить(` with a multiline argument that calls another method.

### Valid Negative Twins

1. `Метод(ДругойМетод())` on one physical line when `allowOneliner=true`.
2. Multiline call whose nested call is only `НСтр(...)`.
3. Multiline call whose nested call is only `ПредопределенноеЗначение(...)`.

### Edge Examples

- Comments: comments inside or near an argument list do not create nested-call facts.
- Strings: call-looking text inside string literals must not report.
- Preprocessor: not a separate semantic target.
- Multiline: only multiline outer calls with multiline argument expressions are reportable.
- Nested constructs: nested parameterized constructors are reportable unless they are the outer expression being checked.
- BSL/SDBL variants, if relevant: SDBL is not relevant.
