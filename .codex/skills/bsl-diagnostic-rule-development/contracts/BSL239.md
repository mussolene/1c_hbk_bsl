# BSL239 ReservedParameterNames Contract

## Rule Identity

- Code: BSL239
- BSLLS compatible name: ReservedParameterNames
- Public name/i18n key: BSL239 / ReservedParameterNames
- Default message/i18n key: RULE_MESSAGES_RU["BSL239"]
- Description/i18n key: RULE_METADATA["BSL239"].description
- Severity: WARNING
- Parameters/defaults: `reservedWords=""`; empty default disables concrete matches.
- Rule status: verified

## Standard And Product Decision

- Standard or product policy: project teams may forbid parameter names that collide with reserved product/system names.
- Why this diagnostic exists: reserved-like parameter names make procedure signatures ambiguous and harder to maintain.
- Non-goals: local variables, method names, fields, attributes, or parameters when `reservedWords` is empty.
- Keep/drop decision: keep as a BSLLS-compatible configurable naming diagnostic.

## Semantic Oracle

- Checked language fact: a procedure/function parameter name fully matches the configured `reservedWords` regular expression.
- Must diagnose when: `reservedWords` is configured and a declared method parameter name matches it.
- Must not diagnose when: `reservedWords` is empty, the text is not a method parameter, or only a substring matches.
- Diagnostic anchor token/range: parameter identifier span in the method header.
- Quick-fix target, if any: rename the parameter to a non-reserved project name.

## CST Or Domain Fact Model

- Parser/tree source: module procedure/function domain facts collected from CST/header parsing.
- CST/domain object types: procedure/function declaration and parameter identifiers.
- Extracted attributes: parameter name, header line/column, configured regex, and severity.
- Parse-error behavior: report only when method parameters were recovered as method facts; BSL001 owns syntax errors.
- Textual/regex behavior, only if genuinely textual: regex is the user-configured reserved-word matcher over extracted parameter names, not over raw source text.

### Invalid Examples

1. `Процедура Заполнить(Дата)` with `reservedWords="Дата|Date"`.
2. `Function Build(Date)` with `reservedWords="Дата|Date"`.
3. `Процедура Проверить(Ссылка)` with `reservedWords="Ссылка|Ref"`.

### Valid Negative Twins

1. `Процедура Заполнить(ДатаДокумента)` with `reservedWords="Дата|Date"`.

3. `Процедура Заполнить(Дата)` when `reservedWords=""`.
