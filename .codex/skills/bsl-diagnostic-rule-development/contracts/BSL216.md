## Standard And Product Decision

- Standard or product policy: Operators, separators, and selected keywords should be spaced according to common BSL formatting conventions.
- Why this diagnostic exists: It flags missing spaces that hurt readability and formatter consistency.
- Non-goals: Tokens inside strings/comments and syntax positions where no space is required.
- Keep/drop decision: keep

## Semantic Oracle

- Checked language fact: A source code token pair lacks required whitespace around comparison, arithmetic, comma, semicolon, or selected keyword tokens.
- Must diagnose when: A code line contains a spacing violation after comments/strings are masked.
- Must not diagnose when: The same token appears in a string/comment or already has required whitespace.
- Diagnostic anchor token/range: the operator, separator, or keyword token missing surrounding whitespace.
- Quick-fix target, if any: insert the missing space manually or through formatter.

## CST Or Domain Fact Model

- Parser/tree source: `DocumentSnapshot.missing_space_facts`.

- Extracted attributes: line index, token start, token end, token family.
- Parse-error behavior: textual spacing scan can run without valid CST.
- Textual/regex behavior, only if genuinely textual: this is a textual formatting rule, so lexical spacing patterns are intentional.

## Examples

### Invalid Examples

1. A comparison operator has no required left or right space.
2. A semicolon is immediately followed by code or a comment without required space.
3. A comma or keyword lacks required adjacent whitespace.

### Valid Negative Twins

1. The same operator has spaces on both required sides.
2. The token appears inside a string literal.
3. The token appears inside a comment.

### Edge Examples

- Comments: comment text is excluded from code spacing checks.
- Strings: masked before spacing checks.
- Preprocessor: not a separate target unless represented as a checked line.
- Multiline: each physical line is checked independently.
- Nested constructs: not relevant.
- BSL/SDBL variants, if relevant: SDBL query text is not the primary target.
