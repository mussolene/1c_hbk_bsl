# BSL231 Contract

## Rule Identity

- Code: BSL231
- BSLLS compatible name: PrivilegedModuleMethodCall
- Public name/i18n key: BSL231 / PrivilegedModuleMethodCall
- Default message/i18n key: RULE_MESSAGES_RU["BSL231"]
- Description/i18n key: RULE_METADATA["BSL231"].description
- Severity: WARNING
- Parameters/defaults: BSLLS has `validateNestedCalls=true`; project implementation keeps the default behavior.
- Rule status: verified

## Standard And Product Decision

- Standard or product policy: calls to public methods of privileged common modules require review because they can bypass ordinary rights checks.
- Why this diagnostic exists: a normal module can invoke privileged-module API and indirectly execute privileged code.
- Non-goals: reporting private or missing methods, non-privileged common modules, or local methods outside privileged common modules.
- Keep/drop decision: keep as a BSLLS-compatible metadata/reference diagnostic.

## Semantic Oracle

- Checked language fact: a call reference resolves to an exported method whose declaring common module has `<Privileged>true</Privileged>`.
- Must diagnose when: code calls an exported method of a privileged common module, including nested unqualified calls inside that privileged module.
- Must not diagnose when: the target method is private, missing, declared in a non-privileged module, or appears only inside comments/strings.
- Diagnostic anchor token/range: the called method name, matching BSLLS selection range.
- Quick-fix target, if any: review the access path or move the privileged action behind an explicitly safe API.

## CST Or Domain Fact Model

- Parser/tree source: BSL module text plus configuration XML metadata.
- CST/domain object types: common module privilege map, common module exported procedure/function name cache, cleaned BSL lines.
- Extracted attributes: current common module name, privileged flag, exported method names, qualified and nested call method token spans.
- Parse-error behavior: textual call scan works on cleaned lines; comments and string literals are masked before matching.
- Textual/regex behavior, only if genuinely textual: lightweight call-token scan is used as the local substitute for BSLLS reference index.

## Examples

### Invalid Examples

1. `ПривилегированныйМодуль.ПубличнаяФункция();` where the method is exported.
2. `ПривилегированныйМодуль.ПубличнаяПроцедура();` from an ordinary common module.
3. Inside a privileged module private method, `ПубличнаяФункция();` calls an exported method of the same module.

### Valid Negative Twins

1. `ПривилегированныйМодуль.ПриватнаяФункция();` where the method is not exported.
2. `ОбычныйМодуль.ПубличнаяФункция();` where the module is not privileged.
3. A string/comment containing `ПривилегированныйМодуль.ПубличнаяФункция();`.

### Edge Examples

- Comments: masked before matching.
- Strings: masked before matching.
- Preprocessor: no special handling.
- Multiline: calls split across lines are not matched by the lightweight scanner.
- Nested constructs: same-module unqualified calls are checked only inside privileged common modules.
- BSL/SDBL variants, if relevant: not relevant.

## Performance Contract

- Traversal/fact source: one pass over cleaned module lines plus cached metadata/export indexes.
- Expected complexity: O(module lines + matched call tokens), with cached XML and module export parsing.
- Shared-pass reuse: shares metadata caches with BSL213, BSL214, BSL232, and BSL242.
- Before/after measurement, if changed: targeted pytest runtime and private parity runtime are recorded as OACS evidence for the closure iteration.

## Implementation Decision

- Change target: BSL231 branch in `query_metadata_rules.py`.
- Delta category fixed by this change: semantic over-reporting caused by treating every method name on a privileged module as a privileged public reference.
- Why not another layer: the local engine does not have BSLLS reference index, so the narrow exported-method cache is the closest available semantic source.
- Rollback signal: private/missing privileged-module methods report again, nested public calls inside privileged modules disappear, or private parity regains BSL231 deltas.
