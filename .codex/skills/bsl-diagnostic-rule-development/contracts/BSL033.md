## Standard And Product Decision

- Standard or product policy: query execution inside loops should be avoided because it repeatedly hits the database.
- Why this diagnostic exists: moving a query outside the loop and using set parameters is usually faster and safer.
- Non-goals: query text validation, query metadata validation, or unknown object `Execute()` calls not proven to be query-like.
- Keep/drop decision: keep as a BSLLS-compatible performance diagnostic.

## Semantic Oracle

- Checked language fact: a query-like object is executed inside a loop.
- Must diagnose when: a variable assigned from `Новый Запрос`/`Query` or related query-builder types is executed with `Выполнить()`/`Execute()` in a loop body.
- Must not diagnose when: the object type is unknown, the execution is outside a loop, or the call is not query execution.
- Diagnostic anchor token/range: full execute call expression, including chained call suffixes when present.
- Quick-fix target, if any: move the query outside the loop and pass the whole collection as a query parameter.

## CST Or Domain Fact Model

- Parser/tree source: BSL tree-sitter CST through shared `ts_nodes_for_types`.
- CST/domain object types: procedure facts, `assignment_statement`, `new_expression`, `method_call`, `call_expression`, `access`, and ancestor loop nodes (`for_each_statement`, `for_statement`, `while_statement`).
- Extracted attributes: query variable name/type, loop membership, execute call start/end range, and severity.
- Parse-error behavior: skip uncertain procedure containment when procedure facts are unavailable; BSL001 owns syntax errors.
- Textual/regex behavior, only if genuinely textual: none for the active CST path.

## Examples

### Invalid Examples

1. `Для Каждого Элемент Из Коллекция Цикл Результат = Запрос.Выполнить(); КонецЦикла;`
2. `Пока Условие Цикл Рез = QueryObject.Execute(); КонецЦикла;`
3. `Для Каждого Элемент Из Коллекция Цикл Данные = Запрос.Выполнить().Выгрузить(); КонецЦикла;`

### Valid Negative Twins

1. `Запрос = Новый Запрос; Результат = Запрос.Выполнить();`
2. `Пока Условие Цикл Ответ = HTTPЗапрос.Execute(); КонецЦикла;`
3. `Для Каждого Элемент Из Коллекция Цикл Сообщить(Элемент); КонецЦикла;`

### Edge Examples

- Comments: ignored by the procedure body scanner.
- Strings: ignored because query execution must be an executable statement.
- Preprocessor: ordinary procedure/loop fact extraction applies.
- Multiline: current implementation handles line-local execute calls.
- Nested constructs: loop-line membership covers nested loop bodies.
- BSL/SDBL variants, if relevant: query text is outside this rule; this rule checks BSL execution location.
