## Standard And Product Decision

- Standard or product policy: cached common modules should be named so their reuse/caching behavior is visible from the module name.
- Why this diagnostic exists: `ReturnValuesReuse` changes runtime semantics; names without a cached/reuse marker make common-module behavior harder to understand.
- Non-goals: non-common modules, common modules without cached `ReturnValuesReuse`, missing/unreadable XML, and other common-module naming rules.
- Keep/drop decision: keep as a BSLLS-compatible common-module naming diagnostic.

## Semantic Oracle

- Checked language fact: a common module has cached return-value reuse and its metadata name does not contain a cached/reuse marker.
- Must diagnose when: sibling common-module XML exists, `ReturnValuesReuse` is a cached mode such as `DuringRequest` or `DuringSession`, and the module name does not match the cached-name token set.
- Must not diagnose when: XML is missing/unreadable, the metadata is not a common module, return-value reuse is not cached, or the module name already contains `ПовтИсп`, `ПовторноеИспользование`, or `Cached`.
- Diagnostic anchor token/range: the first non-empty/non-BOM line of the module file.
- Quick-fix target, if any: rename the common module to include an accepted cached/reuse marker.

## CST Or Domain Fact Model

- Parser/tree source: XML metadata for common-module flags/name; BSL text is used for the diagnostic anchor.
- CST/domain object types: common-module XML snapshot and first non-empty module line.
- Extracted attributes: module name, `ReturnValuesReuse`, cached-mode boolean, and anchor line range.
- Parse-error behavior: BSL parse errors do not affect this XML-driven naming rule.
- Textual/regex behavior, only if genuinely textual: XML tags and module-name token matching are textual metadata conventions.

## Examples

### Invalid Examples

1. Common module named `ОбменДанными` with `ReturnValuesReuse=DuringRequest`.
2. Common module named `ServerUtils` with `ReturnValuesReuse=DuringSession`.
3. Cached common module whose name contains neither Russian nor English cached/reuse marker.

### Valid Negative Twins

1. Common module named `ОбменДаннымиПовтИсп` with cached reuse.
2. Common module named `CachedServerUtils` with cached reuse.
3. Common module without cached return-value reuse.

### Edge Examples

- Comments: comments may be the diagnostic anchor when they are the first real module line.
- Strings: BSL strings do not affect XML naming.
- Preprocessor: not a separate semantic target for this rule.
- Multiline: XML formatting may be multiline; tag extraction is fixed-tag based.
- Nested constructs: BSL procedures/functions do not affect this rule.
- BSL/SDBL variants, if relevant: SDBL is not relevant.
