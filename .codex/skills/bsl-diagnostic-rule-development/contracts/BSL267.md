## Standard And Product Decision

- Standard or product policy: configuration code should avoid runtime loading or creation of external processing, reports, or configuration extensions without explicit architectural control.
- Why this diagnostic exists: external-code tools create security and maintainability risks because they can execute code outside the reviewed configuration surface.
- Non-goals: diagnosing ordinary method names `Создать` / `Подключить` on arbitrary objects, proving safe mode state, or following dynamic references.
- Keep/drop decision: keep as a BSLLS-compatible security/correctness diagnostic.

## Semantic Oracle

- Checked language fact: a call to `Создать` / `Create` or `Подключить` / `Connect` on one of the external-code manager objects.
- Must diagnose when: executable code calls these methods on `ВнешниеОбработки`, `ExternalDataProcessors`, `ВнешниеОтчеты`, `ExternalReports`, `РасширенияКонфигурации`, or `ConfigurationExtensions`.
- Must not diagnose when: the text appears in comments/strings, the receiver is not one of the configured manager objects, or the method name belongs to an unrelated object.
- Diagnostic anchor token/range: from the manager object token through the call chain end.
- Quick-fix target, if any: replace runtime external-code loading with a reviewed built-in mechanism or remove the unsafe call.

## CST Or Domain Fact Model

- Parser/tree source: masked executable source lines.
- CST/domain object types: manager-object token, method token, call parentheses, and call-chain end.
- Extracted attributes: receiver name, method name, start range, call end range, and multiline call end.
- Parse-error behavior: malformed syntax is not the target; BSL001 owns syntax errors.
- Textual/regex behavior, only if genuinely textual: a bounded manager/method call regex is acceptable because the semantic surface is an exact built-in manager call set.

## Examples

### Invalid Examples

1. `Имя = ВнешниеОбработки.Подключить("Путь", Ложь);`
2. `Отчет = ExternalReports.Create(Path);`
3. `Расширение = РасширенияКонфигурации.Создать("Имя");`

### Valid Negative Twins

1. `Объект.Создать("Имя");`
2. `ВнешниеОбработкиОписание = "ВнешниеОбработки.Создать()";`
3. `// ВнешниеОтчеты.Подключить("Путь");`

### Edge Examples

- Comments: ignored through comment stripping.
- Strings: ignored through string masking.
- Preprocessor: not a separate semantic target.
- Multiline: call end is resolved across physical lines.
- Nested constructs: nested arguments do not change the manager/method fact.
- BSL/SDBL variants, if relevant: query text is outside this rule.
