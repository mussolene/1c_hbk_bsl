# BSL097 DeprecatedCurrentDate Contract

## Rule Identity

- Code: BSL097
- BSLLS compatible name: DeprecatedCurrentDate
- Public name/i18n key: BSL097 / DeprecatedCurrentDate
- Default message/i18n key: RULE_MESSAGES_RU["BSL097"]

- Severity: ERROR
- Parameters/defaults: none.
- Rule status: verified

## Standard And Product Decision

- Standard or product policy: global `ТекущаяДата` / `CurrentDate` is deprecated for application logic because it returns server/client local time rather than session-adjusted time.
- Why this diagnostic exists: code should use session-aware alternatives such as `ТекущаяДатаСеанса` or project-standard session date helpers.
- Non-goals: object methods named `ТекущаяДата`, `ТекущаяДатаСеанса`, comments, strings, query text, and unrelated date APIs.
- Keep/drop decision: keep as a BSLLS-compatible standard/deprecated diagnostic.

## Semantic Oracle

- Checked language fact: executable BSL code calls global `ТекущаяДата` / `CurrentDate`.
- Must diagnose when: a clean CST contains a global `method_call` whose identifier is exactly `ТекущаяДата` or `CurrentDate`.
- Must not diagnose when: the name is a member method, part of a longer identifier, inside comments/strings, or syntax-error recovery text.
- Diagnostic anchor token/range: the global call identifier token.
- Quick-fix target, if any: replace with `ТекущаяДатаСеанса` or the project/session date helper appropriate to context.

## CST Or Domain Fact Model

- Parser/tree source: tree-sitter BSL CST and shared global-method-call extractor.

- Parse-error behavior: invalid CST should not produce BSL097 facts; BSL001 owns malformed syntax.
- Textual/regex behavior, only if genuinely textual: none for valid CST paths.
