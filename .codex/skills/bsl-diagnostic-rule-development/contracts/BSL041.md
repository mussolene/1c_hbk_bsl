## Standard And Product Decision

- Standard or product policy: use `СообщениеПользователю` or project message helpers instead of deprecated global `Сообщить`.
- Why this diagnostic exists: `Сообщить` is a legacy user-message API and should not be used for modern UI messaging.
- Non-goals: member methods named `Сообщить`, string/comment text, or broader deprecated API detection.
- Keep/drop decision: keep as a BSLLS-compatible deprecated API diagnostic.
