## Standard And Product Decision

- Standard or product policy: `СтрШаблон` / `StrTemplate` calls must pass values matching the placeholders used by the template string.
- Why this diagnostic exists: a placeholder/value mismatch usually causes wrong runtime text or a runtime failure.
- Non-goals: localization completeness, partial `НСтр` language coverage, or validating dynamically computed template strings.
- Keep/drop decision: keep as a correctness diagnostic.

## Semantic Oracle

- Checked language fact: the maximum placeholder index in a literal template equals the number of substitution arguments after the template argument.
- Must diagnose when: a literal first argument contains placeholders `%1`..`%10` and the number of following arguments differs from the maximum placeholder index.
- Must not diagnose when: the template is not a literal string, placeholders and argument count match, escaped percent syntax is not a placeholder, or no placeholders exist and no substitution arguments are required.
- Diagnostic anchor token/range: the `СтрШаблон` / `StrTemplate` method identifier.
- Quick-fix target, if any: add missing arguments, remove extra arguments, or fix the template placeholders.

## CST Or Domain Fact Model

- Parser/tree source: BSL CST `method_call` nodes via the light call pool.
- CST/domain object types: `method_call`, method identifier, and call argument expressions.
- Extracted attributes: method name, identifier range, first argument literal text, placeholder indexes, and substitution argument count.
- Parse-error behavior: malformed calls are owned by BSL001; this rule requires extractable call arguments.
- Textual/regex behavior, only if genuinely textual: placeholder extraction from a literal template string is textual by language design.

## Examples

### Invalid Examples

1. `СтрШаблон("%1 %2", Значение);`
2. `StrTemplate("%1", A, B);`
3. `СтрШаблон("Значение %10", A);`

### Valid Negative Twins

1. `СтрШаблон("%1 %2", Первое, Второе);`
2. `StrTemplate("%(1)2", A);`
3. `СтрШаблон("Без параметров");`

### Edge Examples

- Comments: not relevant once CST call arguments are extracted.
- Strings: only literal first arguments are checked.
- Preprocessor: not a separate semantic target.
- Multiline: CST argument extraction owns multiline calls.
- Nested constructs: nested calls are handled only when the outer call is `СтрШаблон` / `StrTemplate`.
- BSL/SDBL variants, if relevant: query text is outside this rule.
