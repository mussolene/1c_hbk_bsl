## Standard And Product Decision

- Standard or product policy: selected query fields should have explicit aliases.
- Why this diagnostic exists: explicit aliases stabilize result column names and make query results easier to consume and refactor.
- Non-goals: reporting `*`, fields already using `КАК`/`AS`, source table aliases, query text that cannot form a meaningful select candidate, or dynamic tails that are not complete query statements.
- Keep/drop decision: keep as an SDBL CST-backed query convention diagnostic.

## Semantic Oracle

- Checked language fact: a selected field in a query select-list lacks an explicit field alias.
- Must diagnose when: a complete query or recoverable complete select candidate contains a select-list field without `КАК`/`AS`, excluding `*` and metadata/source objects.
- Must not diagnose when: every selected field has an alias, the expression is `*`, the fragment is only a dynamic condition/union tail without a completed first select statement, or the field belongs to a secondary union branch that BSLLS suppresses.
- Diagnostic anchor token/range: the offending select field expression.
- Quick-fix target, if any: add `КАК <Alias>` to the selected field.

## CST Or Domain Fact Model

- Parser/tree source: extracted query text blocks with tree-sitter SDBL CST.
- CST/domain object types: `field` nodes under `field_list`, `field_alias`, `from_clause`, `union_clause`, and recoverable partial query blocks.
- Extracted attributes: SDBL field range, alias presence, select-list membership, containing query/from clause, union ancestry, and original BSL source position.
- Parse-error behavior: complete clean query blocks are parsed normally; a dynamic fragment beginning with `ОБЪЕДИНИТЬ` may recover the first `ВЫБРАТЬ ... ;` candidate before the next query to match BSLLS.
- Textual/regex behavior, only if genuinely textual: bounded to identifying recoverable dynamic-fragment boundaries before reparsing with the SDBL CST.

### Valid Negative Twins

1. `ВЫБРАТЬ Код КАК Код ИЗ Справочник.Номенклатура`
2. `ВЫБРАТЬ * ИЗ Документ.Заказ`
3. `ВЫБРАТЬ Т.Ссылка КАК Ссылка ИЗ Документ.Заказ КАК Т`

### Edge Examples

- Comments: comments outside query strings are ignored by query extraction.
- Strings: only recognized query string blocks are parsed.
- Preprocessor: not a separate target.
- Multiline: multiline query fields and expression aliases are handled by SDBL CST ranges.
- Nested constructs: `ВЫБОР ... КОНЕЦ` expressions need an alias as one selected field.
- BSL/SDBL variants, if relevant: dynamic `ОБЪЕДИНИТЬ` fragments recover only a completed first `ВЫБРАТЬ ... ;` candidate before a following query.
