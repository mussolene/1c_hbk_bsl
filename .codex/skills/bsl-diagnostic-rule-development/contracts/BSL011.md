## Standard And Product Decision

- Standard or product policy: Procedures and functions should stay readable enough that nested control flow and boolean logic can be reviewed safely.
- Why this diagnostic exists: It flags methods whose cognitive complexity exceeds the configured threshold.
- Non-goals: Module-level code, comments, strings, and methods below or equal to the threshold.
- Keep/drop decision: keep

## Semantic Oracle

- Checked language fact: A procedure or function has cognitive complexity greater than `max_cognitive_complexity`.
- Must diagnose when: The computed cognitive metric for a method exceeds the configured threshold.
- Must not diagnose when: The method is at or below the threshold, or the apparent control-flow tokens appear only in comments or strings.
- Diagnostic anchor token/range: the method declaration range from `ProcInfo.header_col` to the method header end.
- Quick-fix target, if any: none

## CST Or Domain Fact Model

- Parser/tree source: BSL `DocumentSnapshot.procedures` and cached `complexity_metrics_for_procs`.
- CST/domain object types: `ProcInfo`, method body lines, control-flow and boolean operator tokens.
- Extracted attributes: method start line, header column, end line, nesting level, boolean operators, ternary operations, and branch tokens.
- Parse-error behavior: skip missing procedure model facts; `BSL001` owns broken-document reporting.
- Textual/regex behavior, only if genuinely textual: lexical counting is used inside method body lines after comments and strings are masked.

## Examples

### Invalid Examples

1. A method with nested `Если` branches above the threshold.
2. A method with multiple loop and conditional branches above the threshold.
3. A method combining nested branches and boolean chains above the threshold.

### Valid Negative Twins

1. A flat method with one simple condition below the threshold.
2. A method whose branch-like words appear only in a string.
3. A method whose branch-like words appear only in comments.

### Edge Examples

- Comments: excluded from metric counting.
- Strings: masked before token counting.
- Preprocessor: not a separate target; visible method body lines are counted.
- Multiline: continued boolean expressions contribute to the same method metric.
- Nested constructs: nesting increases cognitive complexity.
- BSL/SDBL variants, if relevant: SDBL is not relevant.
